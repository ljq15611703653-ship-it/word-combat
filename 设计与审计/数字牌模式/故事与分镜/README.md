## 怎么用
1. **先出设定图**：按 `03` 为每个角色生成「全身正面设定图」，选定后命名 `sheet_<角色拼音>.png`；再出面具通用图、小队合照。
2. **再出场景定调图**：`04` 里的场景/道具。
3. **按分镜生成**：每格打开对应 `05_分镜_*.md`，复制「提示词」，同一次对话附上该格出镜角色的设定图 + 一句 “Use the attached character sheets as strict visual references; keep faces, hair, costume and colours identical.”
4. **命名**：生成的图存为 `<id>.png`（如 `L3-pre-1-2.png`），出框元素存为 `<id>_pop.png`，放进引擎的图片目录，与 `07_panels.json` 里的 `image` 字段对应。
5. 画面不含文字，台词/音效由游戏按 `07` 叠加。

## id 规则
`L<关>-<pre|post>-<页>-<格>`，如 `L3-pre-1-2`。序章 `L0-pre-…`；揭示、结局为 `level=15`，id 为 `L15-reveal-…`、`L15-endA-…`、`L15-endB-…`，`when=post`，并带 `section`（reveal/ending_A/ending_B）。

## 设计说明
- 对手混编：第 1~9 关用十二个起义军成员的混编面具队，让玩家前期当“模拟体”；第 10~13 关面具裂开，按双生/长明/待定/赤心四个小队分别出场；第 14 关是叶晴、宋伯、阿豆。
- 咬合：词位=叶栖，数位=小满，第三位（引用位或速位，待定）=柯谦，正文先用中性写法；小满“一，免费”，柯谦把重要的事写在书页背面；过载=义体过载；断联=灰白线框+丢记忆。
- 同伴细节：红线、敲手腕、荔枝糖纸、硬币、艾草香、缺指义手是暗示的主要载体。

## 播放流程（已按用户确认调整）
每关：**关前漫画组（when=pre）→ 关卡进行，中间用视觉小说式底部对话框（角色半身立绘站左/右 + 底部文字框）→ 关后漫画组（when=post）**。漫画只在每关开头和结尾，中间不再配漫画格；`07_panels.json` 里每关只有 pre/post 两组。序章为 pre，揭示与结局为 post（带 section 字段）。

对话框数据在 `06_关卡对话.json`：`intro/outro`（进出关对话）、`rounds`（每关 1~2 轮：`say` 为该轮开始前，`after` 为该轮结算后，每条 ≤30 字，承载暗示）、`hints`（暗示备忘，供回看）。每条台词含 `who/text/expr/side`。

### 表情词表（固定 6 个，与 03 设定表「表情集」六格顺序一致）
`neutral`（平静）、`smile`（笑）、`angry`（怒）、`shock`（惊）、`sad`（悲）、`smirk`（坏笑/嘲讽）。每个角色按此顺序画六张半身表情。
### 站位
叶栖固定 left；其余所有角色固定 right（小满、柯谦、公司人物、对手各自出场时站右）。

### 页如何由游戏拼出来（多边形版）
1. 读 `07_panels.json` 的 `layouts`（6 个多边形模板；每格含 polygon、z、ratio、safe；每模板含 blocks 装饰色块）。
2. 按 `level`、`when` 过滤，再按 `page` 分页；同页内按 `slot`（出现顺序）。
3. 一页开始：铺纸张底色；按 z 从小到大绘制每格：用该格 `polygon`（乘以页画布宽高）作为遮罩，把格子图以 cover 方式放进多边形外接矩形再裁切（图中主体在 `safe` 内，不会被裁掉）；格间缝隙宽窄不一是模板本身决定的，z 大的盖住 z 小的。
4. 装饰色块（该页第 1 格的 `blocks`）：按多边形绘制，颜色取 `color`，`fill`=halftone 用网点图案、solid 纯色、misregister 用青/品红两层错位叠加；`blend`=multiply/screen/normal；允许超出画布（bleed），在所有格子之上、出框层之下。
5. 出框层：带 `pop` 的格子，在该格出现的同时，把 `pop.image`（绿幕图，抠掉 #00FF00）按 `pos`（中心锚点，页内归一化）、`scale`（相对页宽）绘制在最上层，盖在 `over` 指定的格子之上；可做轻微入场弹出动画。
6. 每格进入时按 `camera`（推拉）微动，`lines` 与 `sfx` 同步；一页的格子都出现后等点击翻页。
7. 每格图是单独生成的，人物一致性靠设定图；不要让 GPT 一次画整页。

## 故事层与教学层分离（节拍 beat）
- 故事层：每一关是一个**节拍**（beat），只有场景、对手小队、暗示、关前关后漫画和对话；标题和文本里不出现任何规则词。文件里的 `level` 字段 = beat 编号（06/07 另有 `beat` 字段，含义相同）。
- 教学层：`08_课程表.json` 把「教什么、教几个、什么顺序」放在故事之外，当前全部 `teach: null`。教学内容**由课程表在运行时挂到节拍上**，节拍可以合并/删减/重排，所以每个节拍的故事都能独立成立；规则提示由别的系统负责。
- 节拍标题（中性）：1 校准、2 回响、3 醒来、4 试探、5 街灯、6 雨夜、7 屋顶、8 旧厂、9 暗处、10 双生、11 长明、12 待定、13 赤心、14 毕业。

### 节拍数变化时如何重分配暗示
暗示按**相对阶段**写：前期（前 20%，只有感官：哼调子、敲手腕、糖纸）、前中期（20%~45%，符号：涂鸦、口头禅、双胞胎同步）、中期（45%~65%，动作与语言：行礼、叶栖自己的口头禅、缺指机械手）、后期（65%~92%，四个小队各占一节拍，主角认出并自欺）、揭示前（最后一个节拍，姐姐、宋伯、阿豆）。
- 变成 10 个节拍：前期 2（保留调子+敲手腕，糖纸并入第 3）、前中期 2、中期 2、后期 3（把四个小队中最弱的一队并入前一队，如“待定”并入“双生”）、最后 1。
- 变成 18 个节拍：前期 4、前中期 3、中期 4、后期四个小队各 1 并在每队前后各加 1 个只含人物日常、不含暗示的缓冲节拍，最后 1；新增节拍用 `data` 里的“日常/缓冲”类漫画（宿舍、食堂、屋顶夜话）即可。
- 原则：①糖纸、硬币、艾草、红线等“物件型暗示”要在前半出现一次，后半回收一次；②叶栖口头禅被对手说出，必须在后期之前；③四个小队必须全部出场，且最后一个对手永远是叶晴一队；④断联带来的记忆缺失要在前半先出现一次（柯谦）。
