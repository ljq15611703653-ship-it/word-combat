# 词牌组装演出

入口 `player.ts`，DOM/CSS/SVG，读取真实结算回放，不修改战斗结果。

## 流程

可操作词牌（由 AST 转词序列，排除自动奖励与全部灰色补词）从句子中飞起、旋转并扣合。牌面使用施法者色系的小色块，允许轻微重叠。每个实际效果执行前，同一组词牌重新组合成对应结构；释放后再进入下一效果。演出结束归位。攻击发射组合中的数字牌，同时将原句对应数字变暗，结束恢复。

| 效果 | 组装和演出 |
|---|---|
| 攻击、重复攻击、反弹、无视防御 | 错位刃阵，蓄能、后坐、数字释放、粗光带和命中碎片；每次实际命中独立呈现 |
| 减伤 | 弧形护片组装、防御板落到目标、屏障留场；受到攻击才闪烁抵挡，不将逐击减伤误作盾池 |
| 治疗、净化 | 十字修复结构，修复光效；净化移除真实目标上的状态标记 |
| 灼烧、易伤、衰弱 | 环状组合与状态印记，分别配火星、裂纹、下压箭头；状态按真实持续时间留场 |
| 转移、反弹 | 折转结构、双向箭头；真实反弹目标来自结算事件 |
| 移除保护、移除长期句 | 钳形组合、拆解碎片，精确作用于引擎给出的目标；不误清状态 |
| 延后 | 阶梯组合、目标句位移、延后秒数或移出时间轴提示 |
| 引用量 | 数据阶梯，数字调入与实际引用值显示，再切换到该效果的攻击/防御/治疗结构 |
| 条件、断言分支 | 判定结构、成立/不成立/否则反馈，然后只演出实际执行的分支 |
| 每当、不得、定时、断言、无视长期句 | 环形监测/锁定结构，持续标记与期限；到触发时执行对应效果 |
| 定时兑现 | 核心释放结构，随后逐一演出真实兑现效果 |
| 回合末灼烧、过热、击倒、骰子 | 原地状态/热浪、受击和倒下碎片；骰子使用现有投骰演出 |

## 时间与生命周期

正常速度不再按一轮句子数量强制压到8秒；快速档保留，关闭档直接应用回放。句中效果跟随实际结算顺序，不同时乱飞。跳过完成事件应用并清理临时层、镜头和出招标记。地台移除，出招时几层人物色光圈升起并消散。

持续标记不属于临时特效层。结算后与下一轮根据真实 unitView 对齐；本轮减伤在本轮演出结束退场；施法者死亡与移除按真实规则处理。

## 精确事件

`engine-vfx-trace-patch.mjs` 给引擎增加只读trace：转移、反弹、移除、净化、全局编号延后、引用量、条件结果、无视和兑现。`sync-engine.mjs` 自动重施，不改变费用、伤害、时序或胜负。`api.ts` 转为 cue 事件，不再在前置演出里猜移除对象或预演未选分支。

## 检查

- `vfx-all-effects-test.mjs`：23种效果与多效果切换，动画清理、镜头归位和页面错误。
- `vfx-trace-test.ts`：真实引擎的移除目标、全局编号延后、反弹和引用值。
- `vfx-real-game-test.mjs`：真实电脑对局与跳过清理。
- `vfx-readable-test.mjs`：攻击/抵挡顺序、逐击减伤不消耗、标记失效。

仍保留旧演出方法供对照，当前入口不调用旧的整句穹顶拼装。引擎回放中原有不屈等血量中间值缺口仍由 Battle 在演出结束对齐。
