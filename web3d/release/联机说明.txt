词战 · 局域网联机版
==================

一、准备（只要房主一台电脑做）
1. 安装 Node.js（LTS 版即可）：https://nodejs.org ，国内可用 https://npmmirror.com/mirrors/node/
2. 把这个压缩包解压到任意文件夹（路径里有中文也没关系）。

二、开服（房主）
1. 双击 start.bat（Mac / Linux 运行 start.sh）。
2. 窗口里会显示两行地址：
   本机打开      http://localhost:8787/
   局域网其他人  http://192.168.x.x:8787/
3. 房主自己用浏览器打开第一行；把第二行发给朋友。
4. 窗口不要关，关了服务器就停了。

三、加入（朋友）
1. 和房主连同一个 Wi-Fi / 路由器（手机热点也行）。
2. 浏览器打开房主发来的 http://192.168.x.x:8787/ 。

四、开打
两个人都在主菜单点「打真人」→ 选卡组 →「开始匹配」，两个人都点了就自动配对开打，不用房间号。
没人陪的时候主菜单「打电脑」「新手教程」照样能玩。

五、朋友打不开怎么办
1. 第一次运行 start.bat 时 Windows 弹出防火墙提示，勾「专用网络」点允许。
2. 还不行：右键「开放防火墙.ps1」→「使用 PowerShell 运行」（要管理员），会放行 8787 端口；不用了再运行一次并加 -Remove 删除。
3. 网络类型要是「专用」：设置 → 网络和 Internet → 属性 → 网络配置文件选「专用」。
4. 路由器开了「AP 隔离 / 访客网络」时同一个 Wi-Fi 也互相连不上，换手机热点。
5. 朋友浏览器开着代理（梯子）时，把房主 IP 加进代理的绕过名单，或者先关掉代理。
6. 8787 端口被占用：在 start.bat 同目录打开命令行，先 set PORT=8791 再运行 start.bat，地址里的端口跟着变。
