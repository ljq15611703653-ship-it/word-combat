# 针对性复测报告（真实逐张构筑流程）

脚本：`tests/t_cnt_run.gd`（跑局+统计，输出 jsonl）、`tests/t_cnt_match.gd`（Match 子类：记录拼卡、可选“更爱针对”出招实验）、`tests/t_cnt_empty.gd`（空卡诊断）。
数据：`D:/work/cnt/*.jsonl`，分析脚本 `D:/work/cnt/ana.py`。均未改动仓库已有文件。
基线 120 局：ai_epsilon 0.12 ×60（种子 1–60）+ 0.0 ×60（种子 2001–2060），流程 `Match.start(false, seed, false)` + `begin_staged()` + `step_auto()`。

## 1. 结论一句话
你的假设**部分成立，但不是主因**。“起手晚”基本不是问题（起手秒仅 ms=3，打断实际命中也成功）。真正的断点依次是：
1. **行动点买不起**：打断卡操作费 39（偶尔 43），持有者回合开始时平均只有 29 点，87% 的“持卡回合”根本买不起（电脑把点数都花在 22 点的单点攻击上）；
2. **买得起也不宣告**：买得起且可用的 59 个技能-回合里只宣告了 6 次（10%）；先手 1/34、后手 5/25；
3. **打断力度很窄**：力度换算 1.25×P，打断卡只能压制操作费 ≤22~24 的技能，实际 5 次命中的全是 22~23 费的普通单点攻击，打不了大招；
4. **更上游的问题：第 4 张卡有 42% 是空卡**（见 §4），而第 4 张本应是看到对手 3 张牌后最能针对的一张。

### b. 验收标准
1. **每局平均 ≥1 次成功反制：不达标。** 严格口径（打断成功+改道/转移+转伤为疗）= **0.158 次/局**，至少有 1 次的局占 11.7%；宽口径（再加“明显吃伤轮”）0.175 次/局，13.3% 的局。
2. **对手亮首挡后，己方多段攻击比例明显更高：不达标。** 第 2 张起拼的所有卡：对手已亮牌带首挡时 1/25 = **4.0%**；不带首挡时 25/573 = **4.4%**（无差别）。只看攻击卡：1/4 = 25% vs 25/138 = 18%（样本太小，不可信）。原因：能触发该加分的局面本身很少（首挡只占已亮牌 4%），而且电脑几乎凑不出带“重复”的路线。
3. **针对一方胜率更高：不达标（方向相反）。** 标记 = 拼卡时 Coach._relevance 的 bonus>0。第 2 张起仅 10.5% 的卡带标记。针对张数更多的一方胜率 14/41 = **34%**，更少的一方 66%；有 ≥1 张针对卡的一方胜率 21/55 = 38%，0 张的 94/175 = 54%。说明现有“针对”主要是弱的一档（对手血少→拿单点、对手进攻多→拿守/反），并且这些反制自身很少真正起效，反而拖慢了进攻。（相关而非因果：被标记者本身就是偏守的路线。）
4. **进攻卡占比：** 非空卡里 atk 占 **48.1%**（403/838），ctl 21.7%、trap 11.2%、def 9.2%、heal 8.0%；若把空卡也算进分母占 42%。已明显低于纯进攻，可接受。

## 3. 漏斗诊断
### 3.1 时间类（打断/沉默/延后）
| 步骤 | 打断 | 沉默 | 延后 |
|---|---|---|---|
| 终局牌组中的张数 | 48（44/120 局有） | 5 | 89 |
| 持卡“技能-回合”（活着） | 445 | 42 | 818 |
| 买得起且没被沉默 | 59（13%）；29/48 张曾有买得起的回合 | 11（26%） | 818（100%） |
| 其中先手/后手 | 34 / 25 | 7 / 4 | 409 / 409 |
| 被宣告 | 6（占买得起的 10%）；先手 1/34，后手 5/25 | 2（18%） | 73（9%），其中 27 次有目标（先手 10/50，后手 17/23） |
| 有目标（对方有 ≥ 我起手秒的行动） | 5 | 2 | 27 |
| 成功起效 | 5 | — | 27 |
| 落空 | 0 | | 46（先手无目标） |
- 打断卡：操作费 39/43，持有者平均 AP 29.4（分布：20-29 占 47%）。**起手秒 ms=3 不是瓶颈**，宣告起手平均 5.3 秒也够。主要断点：①买不起 87%；②买得起也只 10% 被宣告（AI 的 evaluate 只看分差/生命/AP 差，且先手阶段不会为了“下一轮当后手”而攒 AP）；③力度窄（只能压 ≤22~24 费）。
- 延后：几乎免费，AI 却 91% 的回合不用；宣告时先手方（看不到对手行动）有 40 次打在空气上（time_fail），这是 time_fail 的主要来源。AI 先手宣告延后是纯浪费，且 eps 随机出招也会助长。
- “AI 宣告了但选错起效秒”：基本不是问题——6 次打断宣告里 5 次有目标且全部成功。

共同断点：**电脑几乎不宣告防御/埋伏技能**（3~5%，只有回敬 24%）；而攻击卡宣告率 68–86%。这与 evaluate() 里“防守价值要靠模拟里真有伤害才体现、且技能只保护自己/一轮”有关。同时改道/减伤的起手受“要先于对手起手”限制，AI 若不看见敌方行动（先手）就根本不会选它。

## 4. 额外重大发现：第 4 张卡常是空卡
120 局里 960 个槽位有 122 个空卡（12.7%），其中**第 4 张 99/240 = 41%、第 3 张 23/240 = 10%**；终局每方有技能的卡数：4 张 140 方、3 张 92 方、2 张 8 方。`t_cnt_empty.gd`（30 局）显示：第 4 张拼卡时点数已用 70–80（占位的生命已计入），即使有“可成型路线”（9/25 的空卡）也塞不进预算。原因在 `match.gd:_ai_targeted_card`：前面几张只按各自路线+hp 10 占预算，没有给后面的卡留预算；`_ai_template_card` 虽有 cap 公式但最终也失败。这让“看到对手 3 张牌后拼的最关键一张”常常没有——针对根本没机会发生。

## 5. 实验：更爱针对的出招（仅在 t_cnt_match.gd 子类里覆写 ai_declare，eps=0，50 局×2 位置，对手为原版）
策略 v2：①后手时先单独评估打断/沉默/改道/回敬/减伤/护盾/转伤为疗，只要模拟比现状好（阈值 0.01，原版是 +0.5 且混在所有技能里）就先宣告；②先手持有打断/沉默时，给下一轮留下 (cost−15) 的行动点，不够就不再多花。
| 指标（v2 方 vs 原版方，每局） | v2 | 原版 |
|---|---|---|
| 成功打断 | 0.32 / 0.18（0号位/1号位）| 0.04 / 0.02 |
| 减伤吃掉 | 0.76 / 0.16 | 0 |
| 护盾吸收 | 0.30 / 0 | 0 |
| 监听触发 | 0.62 / 0.42 | 0.22 / 0.24 |
| 胜负 | 48 胜 48 负 4 平 | |
→ 反制出现率提升 4–8 倍（打断每方约 0.25 次/局），仍远低于“每局 ≥1 次”，胜率无变化。打断受限于力度只能压 22 费攻击；v2 下打断卡的“买得起”回合仍只有约 58%/28%。

## 6. 改进建议（按收益排序）
1. **修空卡（最大收益）**：`scripts/game/match.gd` `_ai_targeted_card`（和 `_ai_template_card`）——在 hp 缩减循环前先按“剩余卡数”预留预算：令 `budget_for_this_card = (BUDGET − 已用 − 未拼卡最低占位(每张~14)) `，k≥2 时降 `u.max_hp` 初值（10→7~8）并把 n 缩小；或在 `D.validate` 失败后从**已拼的前几张**里挤 hp（保留 ≥6）再试。预期：第 4 张空卡率 41%→<10%，针对机会 +1 张/局/方。
2. **电脑更会用反制（出招）**：`scripts/ai/ai.gd choose_action`——后手分支把“应对类技能”（interrupt/silence/redirect/mit/shield/convert）单独枚举先评估，门槛降到 +0.01（我的 v2 实现可直接搬）；先手分支加“为下一轮留 AP”的预留（持有打断/沉默时 reserve = cost − ap_gain）。预期：打断 0.04→0.25 次/方/局，减伤/护盾吃伤约 ×4。
3. **禁止先手方宣告打断/延后/沉默**（`Ai.enumerate_actions` 里先手且 enemy_list 为空时过滤 time/打断类）：消除 0.39 次/局的 time_fail 空放（也省 AP）。
4. **让评估看得见防守价值**：`Ai.evaluate` 加“预期被打伤害”项，或在 `_power` 里把已装的减伤/护盾/改道监听按其吸收上限计入；`heal/mit` 宣告率现在只有 3%。
5. **加强拼卡阶段的针对加分**：`coach.gd` `_relevance` 现在只对首挡/治疗对手/埋伏/进攻多/血少 5 个场景给 bonus，且只在极少数局面触发（首挡出现 4%）。建议补：对手有多张攻击→减伤/护盾/改道权重按张数；对手有大招(AOE)→改道/反噬；`match.gd _ai_targeted_card` 里 bonus 乘数由 3.2 提到 4.5，且对“针对首挡”命中时直接强制选 rep 路线。
6. **规则层建议（只建议）**：打断“力度窄”是最大天花板——操作费 39 的卡只能压 ≤22~24 费的技能（≈一个普通单点），而昂贵的大招反而打不断，建议考虑：(a) 打断倍率由 1.25×P 提到 1.5~2×P；(b) 或降低打断卡操作费（目前 39/43，约等于两次普通攻击）；(c) 起手限制不用改（ms=3 不是瓶颈）。行动点 15/轮、封顶 60 让“攒点买打断”几乎不可能，若希望打断成为主流反制，可给“后手方”小额 AP 补偿或让未使用的 AP 保留更多。转伤为疗 4 张 0 次宣告，需先让 AI 会用后再评价强度。
7. **后手优势**：1 号位 58% 胜率，建议另跑 200 局（交换座位）确认，再决定是否对先手/后手加补偿。
