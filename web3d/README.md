# 词战 · 3D 原型（TypeScript + Three.js）

替代 Godot 的新前端。目前只有战斗画面的视觉原型：平放在电路板桌面上的真 3D 玻璃卡（PCB 载板、晶体管、电容、LED 血条）、从卡上投影环竖直浮出的人物全息像、浮在每个人物右侧空位里的句子标注（屏幕空间文字，用引线连到人物）、输入法式拼句键盘、全息时间轴。规则引擎还没有移植，键盘上的词目前任意可按。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 打包到 dist/
```

## 立绘接入

立绘竖直立在卡面的投影环上，像从卡里投射出来的全息像。图放进 `public/portraits/`，在 `src/main.ts` 的 `START` 里用 `art` 指定文件名（不带 .png），`flip: true` 可以镜像。

| 要求 | 说明 |
| --- | --- |
| 格式 | PNG，**带透明通道**（抠好的全身角色，不要背景）。alpha 低于 0.06 的残留会被丢弃 |
| 尺寸 | 832 × 1216（2:3 竖版）。别的比例改 `unitCard.ts` 里的 `832 / 1216` |
| 构图 | 全身，脚落在画面底边附近（脚下就是投影环） |
| 颜色 | 原色即可。默认只叠 15% 的绿色荧光；「效果调试」里可以一键关闭屏幕效果看原图 |

现在用的是 PR #2 的四张角色图（火力大师、支援、黑客、改造狂信徒）。每方三个随从，所以红方暂时复用了其中三张并做了镜像。

## 文件

| 文件 | 内容 |
| --- | --- |
| `src/theme.ts` | 配色：蓝绿主调，红 / 蓝只表示阵营，血量用薄荷绿 / 琥珀 |
| `src/shaders.ts` | 立绘的屏幕失真着色器（扫描线、色散、横向撕裂、滚动亮带、噪点、掉块）；卡内走线的电流光 |
| `src/unitCard.ts` | 战斗单位：PCB 载板（金手指、TO-92 晶体管、电容、芯片）+ 平放的玻璃卡（投影环、信息栏、LED 血条、阵营色角标、走线光）+ 竖直的人物全息像和光柱 + 预警牌 |
| `src/sentencePanel.ts` | 句子标注：引线 + 阵营色竖条 + 名字和时间码 + 一行行的词。类别用文字颜色，强度用字重 / 底光 / 全息渐变，随从是胶囊，数字等宽 |
| `src/words.ts` | 词的类别、强度、价格，以及句子简写的解析 |
| `src/board.ts` | 电路板桌面、全息时间轴和标记 |
| `src/textures.ts` | 运行时用 canvas 画的贴图（电路板、走线、显示屏、预警牌、时间轴刻度） |
| `src/main.ts` | 场景、布局、自动取景、灯光、泛光后期、句子标注的摆放、悬停 / 点选、拼句键盘、演示面板 |

## 失真着色器的参数

| uniform | 作用 |
| --- | --- |
| `uDistort` | 常驻失真强度（扫描线、色散、波纹、噪点、偶发故障），默认 0.4。0 关闭 |
| `uGlitch` | 瞬时撕裂强度，受击时由 `UnitCard.hit()` 拉到 1.4 再衰减 |
| `uMix` | 绿色荧光的混合比例，默认 0.15 |
| `uTint` | 荧光颜色，默认 `#39ff9c` |
