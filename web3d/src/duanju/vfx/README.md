# 技能演出（词牌飞来飞去）vfx/

DOM + CSS + SVG 覆盖层，无 three.js。入口 `player.ts` 的 `VfxCastPlayer implements CastPlayer`（battle.ts 默认使用）。设计参考旧版 `fx/castShow.ts`。

## 一句话的流程
镜头拉近出手者（`.cam` 容器 transform；同秒的多句合并成一次镜头）→ 句子条里的词牌被「拿起」（原文变暗，按字符位置克隆成词牌）→ 飞到盔甲壳（SVG 穹顶）旁，按职业拼装 → 动作前置演出 → 镜头拉开框住目标 → 弹道/光点/光环，**命中那一刻才应用结算**（血条、数字、倒下、首挡/不屈提示）→ 词牌飞回句子条 → 镜头拉回。覆盖层挂在 `.cam` 里，随镜头缩放，坐标是镜头内（布局）坐标。

## 事件 → 演出
| 回放事件 / fire.kinds | 演出 |
| --- | --- |
| hit（有出手者） | 出手者前冲，词牌合成弹道射向目标（见职业），命中环 + 火花，数字 |
| hit src=tgt（转移反弹） | 目标处收缩圈；fire 带 redirect 时壳上先转出反弹箭头 |
| hit src<0（过热/灼烧） | 无弹道；过热全屏红边，灼烧火星 |
| heal | 光点流从出手者到目标，+ 号火花 |
| shield | 六边形碎片飞到目标，护盾罩升起 |
| absorb | 护盾罩闪烁，「挡n」，首挡提示 |
| status | 种子弹飞到目标，落地光环：灼烧火星上升 / 易伤裂纹 / 衰弱下垂箭头 |
| standing（长期句生效） | 词牌钉在壳上闪光，面板里长期句高亮 |
| 非 fire 随从的 hit/heal…（长期句触发） | 触发随从的长期句行亮起 + 「触发」词牌，再以该随从的职业风格打出 |
| kinds=postpone | 目标句词牌被推后（+n秒），推出时间轴（起手+n>20）则碎裂 |
| kinds=strip | 目标壳体拆成六边形碎片落下 |
| kinds=delay / cash | 蓄力球（保持）/ 兑现引爆球，随后是引爆的 hit |
| kinds=quote | 历史数字幽灵从左流向数字词牌，词牌闪光（引用流为主） |
| kinds=nullify（无视） | 弹道换成白色细针 |
| kinds=cond/forbid | 「条件成立 / 条件不成立」飘字 |
| down | 白色碎片 + 倒下标记 |

## 职业变体（配色沿用开局页）
- 并流（品红/黄）：切角词牌，**机械拼装**——逐块咔哒吸合、接缝火花、扫光；弹道=刃；壳=蜂窝六边形。
- 引用流（青/紫）：虚线胶囊词牌，飞行带 3 层拖影；数据线串过词牌依次亮起；弹道=数据珠串；壳=同心数据环。
- 限制流（紫/品红）：粗框词牌，**锁链缠绕**后锁扣合上（词牌变品红双框=锁死）；弹道=锁链鞭 + 尖刺；壳=菱格 + 链带。
- 状态流（黄/青）：圆润词牌，**渗透**（糊开再析出）+ 滴落；弹道=抛物线的墨团，沿途滴落；壳=不规则细胞 + 渗线。

## 接口
- `CastPlayer.play(events, view)`、`skip()`（跳过当前句：完成所有动画并应用事件）、`skipAll?()`（跳过全部：剩余事件瞬时应用）。点击舞台/空格/Enter = 跳过当前句，Esc = 跳过全部；右下角有两个按钮。
- `BattleView.stageEl` 里必须有 `.cam`（battle.ts 的 mount 已包）；单位元素需带 `data-style`（职业 id）与内联 `--c/--c2`。
- 引擎改动（api.ts，记在 engine/PATCHES.md）：fire 事件多了 `kinds / start / ptgt / pn`。
- 测试钩子：`window.__vfxCheck(battle)` 在每次演出结束时被调用（scripts/vfx-smoke.mjs 用它）。

## 速度
菜单「动画速度」：正常 / 快 / 关闭（`view.speed()` = 1 / 2 / 12）。正常：一轮最长约 8 秒（按句数缩放时间系数）；快：约 3 秒；关闭：不建覆盖层，只留飘字数字与血条变化，瞬时。`?speed=0|1|2` 可在 URL 指定（自动测试用）。

## 脚本
- `scripts/vfx-scenes.mjs [端口] [职业] [宽] [高] [场景名]`：合成事件逐动作 × 我方/敌方录帧，输出 `D:/wc/vfx_shots/scenes_<职业>_<宽>/*_sheet.jpg` 联系表（需 python + PIL）。
- `scripts/vfx-smoke.mjs [端口] [局数]`：四个职业电脑代打，随机点跳过，每次演出后检查覆盖层移除、词牌归位、镜头复位。
- `scripts/vfx-probe.mjs`：真实对局连拍。

## 已知不足
- 引擎回放事件本身与最终引擎状态有缺口（不屈保命、倒下时残余护盾、部分护盾事件缺失）：演出后 Battle 会对齐，但演出中血量可能短暂偏差（关闭档同样）。
- 延后的目标随从按「对方宣告序第 ord 个」推测；移除（strip）目标取护盾最多的敌人，都不是引擎给的精确值；定时到期的引爆若在回合末且出手者同上一句，会被当作上一句的效果。
- 镜头拉近在桌面端幅度有限（目标在对侧时要框住双方）；词牌行在面板旁会盖住一部分面板文字（演出期间）；超宽词牌（合并的尾部词）在手机上可能出屏。
- 词牌分词是对句子文本的直译切分，不是真正的「词」对象；首挡/不屈提示靠面板关键词标签推断。
- 没有音效；同一秒并行的多句是依次演出（只合并镜头）。
