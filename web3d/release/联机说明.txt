词战 · 局域网联机版
==================

一、准备（只要房主一台电脑做）
1. 安装 Node.js（LTS 版即可）：https://nodejs.org/zh-cn/download ，国内下载慢可用 https://npmmirror.com/mirrors/node/
2. 把这个压缩包解压到任意文件夹（比如 D:\词战联机版，路径里有中文没关系）。

二、开服（房主）
1. 双击 start.bat（Mac / Linux 运行 start.sh）。
2. 黑窗口里会显示：
   房主：用浏览器打开   http://localhost:8787/
   朋友（和房主连同一个 Wi-Fi / 路由器）打开：
       http://192.168.x.x:8787/    [WLAN]  ← 发这个给朋友
3. 房主自己用浏览器打开 localhost 那行；把标着「← 发这个给朋友」的那行发给朋友。
   标着「虚拟网卡，不是这个」的（比如 192.168.56.1，VirtualBox 装的）朋友连不上，别发。
   换了 Wi-Fi 不用重开，窗口会自动打印新地址。
4. 黑窗口别关，关了服务器就停了。只开一个就够；重复双击会提示「已经有一个在运行」。

三、加入（朋友）
1. 和房主连同一个 Wi-Fi / 路由器（手机热点也行）。
2. 浏览器打开房主发来的 http://192.168.x.x:8787/ 。

四、开打
两个人都在主菜单点「打真人」→ 选卡组 →「开始匹配」，两个人都点了就自动配对开打，不用房间号。
没人陪的时候主菜单「打电脑」「新手教程」照样能玩。
自己先试：同一台电脑开一个普通窗口 + 一个无痕窗口，都打开 localhost 那行，两边都点匹配。

五、朋友打不开怎么办
1. 第一次运行 start.bat 时 Windows 弹出防火墙提示：勾「专用网络」，点允许。
2. 还不行：双击「开放防火墙.bat」（会弹管理员确认），放行 8787-8799 端口。
3. 网络类型要是「专用」：设置 → 网络和 Internet → 点当前的 WLAN / 以太网 → 网络配置文件类型选「专用」。
4. 路由器开了「AP 隔离」或连的是「访客网络」时，同一个 Wi-Fi 也互相连不上，换手机热点。
5. 朋友浏览器开着代理（梯子）时，先关掉代理，或者把房主 IP 加进代理的绕过名单。
6. 8787 被别的程序占了时，服务器会自动改用 8788、8789……，窗口里显示的地址就是实际地址。

六、不在同一个网络（外地朋友）
两个人都装同一个组网工具（Tailscale / ZeroTier / 蒲公英 等）加入同一个网络，
朋友打开「http://房主的虚拟IP:8787/」即可，其余步骤同上。
