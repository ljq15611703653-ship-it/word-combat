## 1. 项目现状（做完了什么）

- **规则引擎**（`scripts/core/`）：技能是一棵节点树，词、费用、起手、人话全由 `grammar.gd` 推出；`engine.gd` 按时间轴结算。
- **电脑对手**（`scripts/ai/`）：按性格构筑、逐个模拟选招。
- **拼句台**（`scripts/compose/`）：玩家把词一张一张拼成一句话，没有模板、没有滑块。
  - `sentence.gd`：句子语法（牌 ⇄ 技能树，往返测试保证全部等价）。
  - `hints.gd`：下一张能接什么、人话提示（“某某”）、三种流派。
  - `composer.gd`：界面（句子轨、钢印、数字牌、词库、模糊匹配模式）。
  - `fuzzy.gd`：模糊匹配（随便扔词，电脑告诉你能拼什么 / 还差什么 / 猜你想拼什么）。
  - `stamp_fx.gd`：钢印与“所有词飞起来合成一句人话”特效。
- **编辑器**（`scripts/ui/editor_popup.gd`）：2D 卡面 + 3D 随从舞台随拼词实时变化；关键词烙在卡上；确定后随从对空气放技能，越强越炫。开局第一张牌从零开始拼并起名。
- **战斗界面**：3D 牌桌、宣告时俯视 5 对 5、意图箭头、桌宠“小词”。
- **队伍与流程（最新）**：每方 **4 张**卡（`deck.gd` 的 `COUNT`），构筑预算 **80 点**，先到 **80 分**。开局发 26 个基础词；**逐张构筑**：每张卡双方同时拼、同时亮相（`match.gd` 的 `begin_staged / commit_card / after_reveal / ai_make_card`，界面 `build_screen.gd`(focus) + `reveal_screen.gd`），亮相后选一袋词再拼下一张，4 张拼完直接开打。没拼到的卡先占 8 点生命；词不够时允许“不装技能，直接亮相”。测试 `tests/t_staged.gd`。旧的“一次构筑整副牌”流程仍保留给批量模拟、调试演示和完整教学。
- **句子语言（最新）**：没有“全部/每个”；目标用 `选择 一个×N`（最多 4，槽展开成 key、key#1…，要选不同的人，候选不够就少选）；统计用 `敌方人数/友方人数`；数值式有 `加上/减去`（中缀、从左到右、最多 6 项）和免费的括号连接牌；`较高者/较低者/差值` 仍是前缀；数值里的 `选择 一个` 也有宣告时的槽（key `v<节点>_<序号>`）。**打断已取消**，沉默没有数字。引擎里仍保留 all/each/interrupt 的内部能力（给内部机制和旧测试用），但 `G.problems` 会拒绝玩家拼出它们。同一秒按先后顺序结算、倒下就救不回；转为治疗先受伤后返还、全队共用一份上限。
- **冒险关卡**：100 关里用了已取消的词的约 38 关在地图上显示“待改”（不挡路）；改写关卡时用 `tools/bootcamp_*.py` 重新写标准答案，验证 `tests/t_bootcamp.gd -- 1 100 naive`。
- **第一局桌宠带打**（`data/first_match.json`，20 步，`--demo=fmtest` 全自动测试）与**回合讲解**（`battle_screen.gd::_coach_round`）。
- **新手引导**（`data/tutorial.json`，57 步，有全自动测试；拼词时点错会被挡住并提示）。
- **3D 词袋**（`scripts/view3d/bag3d.gd`，抽词界面）。
- **长难句训练营（冒险模式）**：**只做了裁判和前 10 关，界面还没做**（见第 3 节）。

## 3. 下一步：把“长难句训练营”做完（冒险模式，100 关）

需求原话：做成冒险模式，敌人当前场面很需要某句话来击败，桌宠手把手教你怎么拼；做 100 关，找 100 种玩家可能想不到的长难句，从简到难。

**已经有的：**
- `scripts/adventure/level_eval.gd`：裁判。给一个关卡和玩家拼的牌，用真实引擎结算一轮；起效时间和要选的目标由裁判从所有可能里自动找“最有利的”，所以关卡考的是句子。
- `tools/bootcamp_dsl.py`：写关卡的 Python 小语言；`tools/bootcamp_ch1.py` 是第一章 10 关的示范；`tools/gen_bootcamp.py` 汇总生成 `data/bootcamp.json`（改完关卡要重新跑：`python tools/gen_bootcamp.py`）。
- `tests/t_bootcamp.gd`：验证每关标准答案能通关；带 `naive` 参数时还检查“没用到关键结构词也能过”的漏洞（目前只有第 4 关，因为恢复也能过，可以接受或收紧）。
- 一关怎么写：场面（我方/敌方随从的血、关键词、状态、敌方已宣告的招）+ 目标（打倒谁、谁不能倒、血量）+ 行动点 + 手里的词（自动 = 标准答案用到的词 + extra）+ 标准答案。第 1 章的 10 关就是范例。
- 计划的章节：1 一句话（做完）、2 连招（并、之后、重复、接续、复制、分流）、3 条件与循环（若、否则、若有、直到、择一、比较）、4 埋伏（当…就…各种事件、转移/转为治疗）、5 控场（打断、延后、提前、沉默、易伤、狂振、牵连、换位、移除）、6 嵌套（监听里套监听 / 若 / 直到 / 接续）、7 终局（带首挡/不屈/免疫的多敌人 boss，6 个效果的长句）。每关都要用 `t_bootcamp.gd` 验证。
- `tests/t_wild.gd` 里有 50 句“玩家可能想拼的天马行空的句子”，可以直接当后面关卡的灵感。

**还没做的：**
1. 关卡内容：第 11~100 关（含每关的 `story`、`why` 文案）。
2. 界面：训练营入口（标题画面）、关卡地图（100 关，顺序解锁，进度存在 `user://settings.cfg`）、关卡画面（场面展示 + 嵌入 `composer.gd`，词库 = 关卡手里的词）、结算动画（可复用 `minion_card.gd` 的动画接口）。
3. 桌宠手把手：按标准答案逐张高亮下一张牌（参考 `scripts/tutorial/tutorial.gd` 的“洞 + 高亮框”，目标名用 `Tut.tag`），并按节点讲每一段在说什么（对象 / 动作 / 数值 / 修饰）；输了要告诉玩家差在哪（可用 `goal_items`）。
4. 允许玩家自己拼出不同于标准答案的解法：裁判只看结果，不比对句子。

## 4. 素材与特效接口（美术、音效、特效都可以直接换）

所有动画与移动逻辑都在代码里，**素材只要按名字放进 `godot/assets/` 就会自动替换代码做的占位**，不用改代码。完整约定、规格、每个目录放什么、怎么检查，都在 **`godot/docs/素材与特效接口.md`**：

| 内容 | 放哪里 | 说明 |
|---|---|---|
| 随从模型（模块化外观） | `assets/minions/` + `data/appearance.json` | 关键词 / 词 / 技能种类 → 挂点配件 |
| 2D 卡面配件、身体图 | `assets/cards/` | `<proc>.png`、`body_<形象>.png` |
| 卡面图标 | `assets/icons/` | `<种类>.png` |
| 战斗特效（打击感） | `data/fx.json` + `assets/fx/*.tscn` | 震屏 / 顿帧 / 大字 / 飞分 / 桌宠台词全可配 |
| 编辑器放技能特效 | `assets/fx/cast_<类别>.tscn` | 越厉害 tier 越高 |
| 钢印特效 | `assets/fx/stamp.tscn` | |
| 音效 | `assets/sfx/<名字>.ogg|wav|mp3` | 名字列表见文档 |
| 桌宠“小词” | `assets/pet/pet_<心情>.png` | |
| 牌桌 / 对手 / 筹码 / 词袋 | `assets/table/` | `table.glb`、`opponent.glb`、`chip_*.glb`、`bag.glb` |
| 字体 | `assets/fonts/` | 裁剪后的思源黑体；新增文案缺字时 `python tools/subset_font.py` |
| 新手引导文案 | `data/tutorial.json` | 步骤、高亮目标、等待的事件 |

## 5. 发布

改完源码后，在仓库根目录：

```bash

Godot --headless --path godot --export-release Web ../web/index.html
# 2. 提交并推送源码
git add -A && git commit -m "..." && git push origin main
# 3. 把 web/ 同步到 gh-pages（Pages 从这个分支发布）
git subtree push --prefix web origin gh-pages
```
