# 句子规则原型（实验用，只在模拟里跑，不进游戏）

> 来源：和用户多轮讨论后的共识（见《设计备忘-状态牌与手牌条》）。这里把共识写成一套**可以直接模拟**的规则，
> 代码在 `web3d/src/lab/`。它是对真实引擎的**简化版**：没有起手秒数，结算按固定阶段；目的只是回答「这套新语法会不会
> 让玩法崩掉、各流派之间是不是互相克制」。数值全部可调，每一轮迭代的改动记在文末「迭代记录」。

## 一、核心共识（不变的原则）
1. **没有「状态牌」，只有句子。** 长期生效的句子留在场上（顶部可见），就是原来那句话本身。
2. **数字牌即价格。** 所有数字（窗口、倍率、触发上限、收紧、效果大小、等待轮数）都吃数字牌；数字 1 免费；
   牌越大，这句话越强。条件的门槛用「收紧」表达：基线很难触发，收紧越大越容易触发（所以越强）。
3. **非数字的宽窄靠词的价格**：比如「任意词」比「攻击词」贵。段数照旧靠行动点。
4. 不要改写、不要暗词/猜、不要硬禁令。「不得」必须带轮次，并且是「违者受罚」而不是真禁止。
5. 「若 成功 / 失败」只能出现在条件句里（接在前一段后面），免费。
6. 每个会反复触发的句子有「触发上限」（每轮最多触发几次，吃数字牌，1 免费）。
7. 触发产生的效果**不会再触发别的触发**（一层封顶）。
8. 出手的随从倒下，它挂着的长期句子就断了。

## 二、对局底座（沿用全灭模式的数值，可调）
- 双方各 3 个随从，生命 `HP`；对面全倒就赢；过热：第 `HEAT_FROM` 轮起，每轮末每个随从受 `轮数−2` 点（挡不住）。
- 行动点：开局 `AP0`，每轮 `+APINC`，上限 `APCAP`。每个随从每轮最多一句（或不出手）。双方轮流宣告，先手每轮交替。
- 数字牌：开局 `CARDS0`，按 `SCHEDULE` 发牌；用过的牌冷却一轮（本轮和下一轮不能用）。数字 ≥2 需要一张**同面值**的牌，1 免费。
- 结算阶段固定顺序：移除 → 减伤 → 恢复 → 伤害 → 兑现。长期句子在**宣告时就生效**，所以本轮后面的事件也算。

## 三、词与句式
**词类（可被引用）**：攻击词（造成）、治疗词（恢复）、防御词（减伤）。**事件**：使用某类词、倒下、受伤。

| 句式 | 写法 | 数字 | 行动点 |
|---|---|---|---|
| 即时效果 | 造成/恢复/减伤 N，选一个目标 | N（≥2 吃牌） | `BASE` |
| 并 | 多段，每段独立 | 各段自己的数字 | 每多一段 `+AND` |
| 条件接续 | 前一段后面接「若 成功/失败，再…」 | 同上 | 免费（只收后一段的费用） |
| 每当 | 每当〔我方/对方〕〔使用某类词/倒下/受伤〕（超过 K 个才触发），〔效果〕，持续 W 轮，每轮最多 C 次 | W、C、收紧 T、效果 N | `STAND`（+任意词 `ANYCLS`） |
| 若没有 | 若〔我方/对方〕本轮没有〔某类词〕，则〔效果〕，持续 W 轮 | W、效果 N | `STAND` |
| 定时 | N 轮后，造成〔引用量〕×M | N、M | `STAND` |
| 提前兑现 | 把我方的定时句现在就结算（引用量按已经过了多久算） | 无 | `CASH` |
| 移除 | 移除一句带有〔某类词〕的话（任意更贵） | 无 | `REMOVE` / `REMOVE_ANY` |

- 收紧：门槛 `K = max(0, THR0 − (T−1))`，T=1（免费）时门槛是 `THR0`，T 越大越容易触发。
- 引用量：A＝已经等了几轮；B＝等待期间某事件发生了几次。
- 效果：对触发源造成伤害（`dmgSrc`，只用于「使用词」事件）、我方全体恢复、我方全体减伤、对面最低血量的造成伤害。

## 四、要验证的问题（每轮迭代都看）
1. 极致攻击流是否仍有性价比，并且是「很克制某种流派、很容易被某种流派克制」（不是被全部吊打，也不是通吃）。
2. 平均轮数、平均句长有没有涨（不能比全灭模式更拖、更冗长）。
3. 有没有一两种写法通吃（需要删/改）。
4. 数字牌够不够用。
5. **电脑的责任**：每轮先判断，异常是设计问题还是电脑不会玩（不用某类句子、不会应对陷阱、乱用行动点）。
