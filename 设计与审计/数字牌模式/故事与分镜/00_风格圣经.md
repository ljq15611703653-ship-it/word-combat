# 00 风格圣经

## 1. 画风总纲
一句话：**手绘感的赛博朋克漫画页**——粗细变化的墨线、粗网点阴影、CMYK 错版（青/品红通道轻微错位）、高饱和撞色、纸张颗粒、夸张透视。

| 项 | 规则 |
|---|---|
| 线条 | 墨线粗细变化明显；轮廓线粗、内部结构线细；关键冲击处允许线条断裂、飞白 |
| 色彩 | 每格最多 3 个主色 + 1 个点缀色；撞色优先（青×品红、橙×靛、黄×紫）；大面积留黑/留白制造静默感 |
| 网点 | 阴影用粗网点（不用平滑渐变）；冲击波用同心网点环；公司场景网点最细最干净，起义军场景网点粗糙 |
| 笔触 | 可见刷痕；背景笔触比人物更松；公司场景笔触最克制 |
| 错版 | 青、品红通道各偏 2~4 像素；强动作格偏得更多，静默格几乎不偏 |
| 纸质 | 全图带轻微纸张纤维和旧印刷污点；不要塑料感的 3D 渲染 |

## 2. 三个阵营的色板与场景风格
| 阵营/场景 | 主色板 | 线与质感 | 情绪 |
|---|---|---|---|
| 义体公司（白色模拟舱、大厅、观察室） | 冰青、亮白、苍青、电蓝高光 | 干净利落的线；光滑渐变与玻璃反光；构图对称、留白多 | 冷、礼貌、无菌 |
| 起义军（面摊、红线、回忆、烛廊） | 余烬橙、锈红、墨黑、火花黄 | 炭笔感粗线；颗粒重；构图偏斜、杂乱、有人味 | 暖、粗糙、旧 |
| 街道 / 模拟空间（样本街道、骰厅、镜厅） | 洋红、青、酸性黄、霓虹粉 | 线框穿帮、扫描线、RGB 分离；构图夸张 | 不稳定、像在做梦 |
| 穿帮（模拟里漏出起义军的东西） | 冷青白里渗入橙红 | 网点层撕开、边缘故障 | 违和、刺痛 |

色板在提示词里对应代码：`C`（公司）`R`（起义军）`T`（街道）`S`（模拟）`X`（穿帮），原文见 `05_分镜_*.md` 每格提示词。

## 3. 分镜语言
- **景别节奏**：大场面 → 特写 → 静默格，三类交替；每关关前 3 格（交代/情绪/对手出场），关后 3 格（爆发/冲击/暗示）。
- **静默格**：无台词无音效，留白 40% 以上，对象常是一双手、一只眼、一根红线。每关关后至少一个静默格，这是暗示的主载体。
- **比例**：16:9 用于大场面与环境；4:3 用于对话中景；1:1 用于特写和细节（红线、硬币、手）；9:16 竖长格用于孤独、高度、入场；偶用 3:2。
- **镜头规则**：公司场景多用平视与正对称；起义军/回忆多用斜构图、手持感；模拟空间多用低角度与广角；叶栖独处用背影或剪影；与「红线」有关的镜头一律是特写。
- **引擎镜头**：`push-in`（推近，用于情绪升高）、`pan-left/right`（环境、对手出场）、`pull-out`（结局收束）、`hold`（静默）。每格 2.5~5 秒。

## 4. GPT 提示词模板
每格最终提示词 = **风格前缀 + 色板句 + 画面描述 + 角色固定描述块（原样） + 无文字后缀**。分镜文件里每格已经拼好，无需再拼。

**风格前缀（固定）**
```
Dynamic comic-panel illustration, hand-painted look with visible brush strokes and ink outlines of varying weight, coarse halftone dot shading, off-register print effect with the cyan and magenta channels slightly misaligned, bold saturated colour clashes, rough paper grain texture, exaggerated dramatic perspective, cinematic composition, cyberpunk future city setting.
```
**画面比例 / 无文字后缀（固定，{ratio} 换成 16:9 / 4:3 / 1:1 / 9:16）**
```
Strictly no text, no letters, no numbers as lettering, no speech bubbles, no captions, no watermark, no logo, no signature; any screens or signs show only abstract glyph-like shapes. Aspect ratio {ratio}.
```
**铁律：画面里不要有文字、对话气泡、水印；文字由游戏叠加。** 招牌、屏幕只画抽象字形。

**保证一致的做法**
1. 先按 `03_角色设定表提示词.md` 生成每个角色的「全身正面设定图」，选定后存档为 `sheet_<角色>.png`。
2. 生成分镜时，同一次对话里**附上出镜角色的设定图**，并在提示词前加一句：“Use the attached character sheets as strict visual references for the characters; keep faces, hair, costume and colours identical.”
3. 角色固定描述块已写进每格提示词，不要改词。
4. 同一场景的多格，附上一张该场景的定调图（`04` 里的场景提示词生成）。
5. 面具靶体：用 `03` 里的面具通用设定图作参考。
6. 若某格人物走样，不要改描述，重新生成并加“match the reference sheet exactly”。
7. 描述里不出现任何作品名、角色名参照、画师名，只用描述性词汇。

## 5. 页布局模板（不规则多边形格）

页画布按 16:9 横版，坐标为 0~1 归一化（左上为原点，顺时针）；允许 <0 或 >1（伸出画框的装饰）。**每格仍是一张独立的图**：生成时用「比例」（多边形外接矩形最接近的标准比例）并把主体放进「安全区」（图本身的归一化矩形 [x,y,w,h]），因为斜切会裁掉边缘。缝宽故意不均，z 大的盖在 z 小的上面。完整数据见 `07_panels.json` 的 `layouts`。

### 出框层
个别格子带单独图层：人物的手/武器/半个身体/道具。提示词要求主体在纯绿 (#00FF00) 或透明背景上、边缘干净、无阴影、无文字，引擎抠色后按 pos（锚点，页内归一化）、scale（相对页宽）盖在 over 指定的格子之上。生成提示词写在对应分镜格下面（以 _pop.png 命名）。

用法：每关关前、关后各 2 页（H/F 交替），序章 3 页（E/B/A），揭示 3 页（A/B/H），结局 A 1 页（E），结局 B 2 页（C/H）。页内格子按 slot 顺序依次出现。
