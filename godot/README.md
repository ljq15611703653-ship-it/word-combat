# 词战：拼词对决 · Godot 原型

一个**可以直接玩**的原型：你对电脑，双方各四张随从，用抽到的词拼出技能，先手锁定、后手看见后应对，再沿同一条 20 秒时间轴结算。

## 怎么运行

- 双击 **`运行游戏.bat`**（会用 `D:\CodexTools\godot-4.7.1\` 里的 Godot 打开本项目）。
- 或者用 Godot 4.7.1 打开 `godot/project.godot`，按 F5。
- 字体用系统字体（微软雅黑）。如果要导出到没有中文字体的机器，需要把一个 CJK 字体放进项目并在 `scripts/ui/main.gd` 里换掉 `SystemFont`。

进游戏后：标题 →「开始对局」→ **拼第 1 张卡（双方同时拼、同时亮相）→ 挑兜子 → 拼第 2 张 → 亮相 → …… 一共 4 张** → 第 1 轮战斗 → 之后每轮：挑兜子 → 调整 → 战斗……「观战演示」是电脑对电脑。

## 规则速览（也写在游戏里的「玩法说明」）

| | |
|---|---|
| 目标 | 打倒一个随从，得到它生命上限那么多分；每轮全部结算后，若至少一方达到 **150 分**，分数较高者获胜（同分继续）；最多 **12 轮**，第 12 轮结束分高者胜、同分平局。倒下的随从**休整一整轮**后满血复出（叠层状态清零）。全队同时倒下会送对方满额分数，但不结束比赛 |
| 构筑 | 四张卡。**100 点** = 四张卡的生命 + 所有技能里填入的数字。每张卡 **1 个技能**（技能里可以用“并”连多个效果）、1 个关键词 |
| 词分三档 | **基础词**（造成、伤害、恢复、减伤、施加、自身/友方/敌方/随从、选择、一个、最前/最后/随机、之后、持续、并……共 22 个）**无限供应**，想用几次用几次，只付价格；**进阶词**（事件监听、条件循环、转移/转为、时间、放大、引用、运算、5 个叠层状态……共 69 个）和 **奇术词**（复制、重复、首挡等关键词……共 10 个）**只能从兜子里拿**，拿到后永久留在词库里（一个词一次只能装在一处） |
| 挑兜子 | 每轮战斗结束后摆出 **5 个兜子**（每个兜子 6 个进阶/奇术词，一眼看得见里面有什么）。**上一轮的先手先挑一个**（先手本来就吃亏），另一方再从剩下的里挑一个，没人要的作废。开局的四张卡也是这样：拼一张、挑一次 |
| 冷却 | 含进阶词的技能用完后要**隔 1 轮**才能再用（`rules.cooldown`，默认 1；只用基础词的技能不受影响）。有了会成长的状态和`持久`，隔轮放就够用，所以冷却不再和叠层打架 |
| 操作费 | 宣告一个技能付：**5 点启动费 + 填入的数字 + 所用词卡价格**（卡上的 ◆；基础动词 1、并 3、进阶词 1～4、叠层状态 2、多选一个每多一个 +2） |
| 行动点 | 开局 45，每轮 +45，最多存 180（原来的 3 倍：一轮可以同时布防守和出进攻，也能攒几轮打大招） |
| 起手 | 操作费每 10 点需要 1 秒起手（读条）。大招慢、小招快。技能落在第几秒由你宣告时选的“起效时间”决定（不早于起手），不由词决定 |
| 一轮 | 第 1 轮构筑完直接开打；第 2 轮起：挑兜子 →（交替的）调整 → **先手一口气宣告完自己的行动，再轮到后手**：后手看见先手的全部行动后再宣告 → 20 秒时间轴一起结算。下一轮交换先手 |
| 每轮干净 | 监听、减伤**只活到本轮结束**；唯一跨轮的是行动点余额、生命、词库、牌组、“每场一次”的关键词，以及下面**会成长的状态** |
| 同一秒的顺序 | 时间改动 → 起手检查 → 建立监听/减伤 → 移除/换位 → 伤害治疗（按先后顺序结算，血量到 0 当场倒下，之后同一秒的治疗救不回）→ 净值结算 → 倒下。回合结束时先结算灼烧 |
| 因果链 | 一个直接事件开一条链；链上**同一个监听器最多触发一次** |

### 会成长的状态（五个，取代旧的狂振/牵连/升华/护盾/易伤/沉默）

`目标 施加 状态 [双倍] [持久]`：

- **施加后是 1 级，之后每过一轮自动 +1 级**（最高 8 级），所以放一次就会自己长大；效果按**指数曲线**，设 k(n) = (1.5ⁿ − 1) ÷ 3：1 级 +17%、3 级 +79%、5 级 +219%、8 级 +821%——前期几乎无感，后期很猛。
- **持续轮数**默认 1 轮（只撑本轮）。每加一个**`持久`**（进阶词），持续轮数翻倍：1 → 2 → 4 → 8 轮。持续轮数是“词”不是数字，所以不占点数，要靠挑兜子抢。
- **续放**：状态还在的时候再放一次，等级 **+1**（`双倍` 一次加 2、4 级），倒计时刷新到这次的末尾（取更晚的，不会缩短）。同一个单位同一种状态**每轮只有第一次施放加级**，同轮再放只刷新倒计时。
- 倒计时走完，整个状态一起消失；倒下、被移除、免疫，都会清掉它。

| 状态 | 常给谁 | 效果（k = 当前等级的曲线值） |
|---|---|---|
| 易伤 | 敌方 | 受到的伤害 ×(1+k) |
| 灼烧 | 敌方 | 每轮结束时受 ⌈k×8⌉ 点伤害 |
| 衰弱 | 敌方 | 造成的伤害 ÷(1+k) |
| 蓄力 | 己方 | 下一次出手的伤害 ×(1+k)，**同一次出手里的所有目标和重复都吃到放大**，打出去时用掉全部等级（群攻叠满蓄力就是“一刀灭队”；必须由有蓄力的那个随从自己出手） |
| 铁壁 | 己方 | 受到的伤害 ÷(1+k) |

语法上谁都可以施加给谁（给自己叠易伤也合法，只是没人这么干）。免疫关键词：免疫易伤、免疫灼烧、免疫衰弱。

### 拆招手段（举例，全是通用词拼出来的）

转移（把这次伤害转给别人，每个被保护者有上限数值）、转为治疗、回敬（按该次伤害回敬来源）、延后 / 提前（设在第几秒，就作用于这一秒之后第一个起效的行动，最晚第 19 秒）、减伤、治疗、五个叠层状态、移除、换位、复制、分流、接续、择一、若/否则……共 101 个词，全部已实现（含同时、直到、本轮、已生效）。**没有打断和护盾**。

## 拼句台（编辑一张卡）

技能**只能拼出来**：没有模板、没有滑块。编辑器右边是拼句台，把词一张一张接成一句话；每个数字也是手填，填完变成一张金属数字牌。

- **句子轨**：拼上去的牌像钢印一样“邦”地烙在轨上（溅火花、冒冲击波）。点数字牌可以改，改完重新烙；点别的牌会把它和后面的牌一起拿下来。
- **现在能接**：每拼一张，下一张能接什么就在最上面放大发亮；不能接的点不了。手里没有但也可能接的词会单独列出。
- **人话提示**：“到目前为止的人话版”，还没定的地方写“某某”。
- **三种流派**：按现在的拼法，接下来可能变成的三句整句（也是词牌拼出来的），点“接这一张”就接上第一张。
- **关键词**：底下摆一排，点一张烙到卡上（一张卡最多一个），再点取下。
- **卡面和随从跟着变**：左边一张 2D 卡面和一个 3D 随从，拼一个词、烙一个关键词，卡面的配件图标和随从的模型就变一次（规则见 `data/appearance.json`）。
- **确定**：所有词牌飞起来，咔咔拼成一句人话；然后随从当场对着空气放这个技能，技能越厉害特效越炫。
- **技能名和卡名**都可以自己填，各有一个“随机”。开局的第一张牌必须起名才能确定。
- 拼出来的是同一种技能树，规则、费用、词的统计一点没变。语法见 `scripts/compose/sentence.gd`（往返测试 `tests/t_sentence.gd`：全部模板和随机技能树都能“树 → 一串牌 → 同一棵树”）。

## 辅助轮（新手教练，可关）

默认打开，标题画面、抽词界面、构筑界面都有「辅助轮：开/关」开关，设置会记住。

- **挑兜子提示**：5 个兜子摆出来时，分析「拿这袋能新凑齐哪些路线、哪些只差几个词」，推荐一个并说明理由。路线共 30 条左右（单点打击、范围·双倍·重复、改道、转伤为疗、延后、铁壁、蓄力、易伤、灼烧、衰弱……）。
- **构筑 / 调整提示**：告诉你「现在就能做、但还没装上的路线」，建议编辑哪张卡、装入什么，以及「再凑几个词就能做什么」。
- **自动组合**（初始构筑）：一键用现有的词配出五张能跑的牌（合法、预算内、尽量每张卡都有技能），之后仍可逐张修改。
- **换一批**：换一种打法再配一遍（均衡 → 狂攻 → 守反 → 控场 → 连锁），每种都有一句话说明；词不够区分时会提示「只够这一种配法」。
- **自动调整**（每轮调整阶段）：给出一条「改哪张卡、装什么」的建议，可以采用（用掉一次调整）、换一个建议或取消。

## 取名

随从卡名和技能名都可以自己填；每个名字旁边的「随机」按钮会按这张卡装的技能（或这个技能的效果）随机取一个。自己起的技能名不会被加序号；**只改名字不算一次调整**。

## 新手教学与桌宠“小词”

**第一局（桌宠带打）**：标题画面第一个按钮。固定的双方牌组和关键局面：对手的守门人带【首挡】，玩家亲手点【连环击】打出“第二下突破首挡”的组合，小词随后解释为什么奏效；再引导改一个数字、看费用变化，然后进入正常对局。步骤文案在 `data/first_match.json`，入口 `main.gd::_start_first_match`，自动测试 `--demo=fmtest`。引导中只许点小词指定的技能/目标，点错会被指出（`Tut.allow_skill / allow_uid / plan`）。

**冒险：长难句训练营**（标题画面）：不是让你拼毫无意义的长句，而是**一关教一个特殊效果怎么用**。20 关、5 章：①一个、两个、全部（`一个 × 3` 就是全部、全队保护、自动目标、把数字算出来）②放大与连击（双倍、重复破首挡、并）③会成长的状态（读懂状态、铁壁、`持久`、衰弱、蓄力、一刀灭队、续放）④埋伏与反应（回敬、转移）⑤综合（双管齐下、忍与爆）。每关有名字有台词的对手、已宣告的招、一个“为什么这样拼”，小词按关卡自己写的词注解（`notes`）一个词一个词地讲，也能“手把手带我拼完”。**有的关是多轮的**（`rounds`），你只在指定的轮出手（`cast_rounds`），队友会自动替你叠状态（`me[i].act`），这样才看得到状态随轮数成长。关卡用 `tools/bootcamp_course.py` 写，`python tools/gen_bootcamp.py` 生成 `data/bootcamp.json`；`tests/t_course.gd` 自测（标准答案必须通关、“天真写法”不能通关）。旧的 100 关在 `tools/old_bootcamp/`，已停用；通关记录随课程版本重置。

**兜子里的词**：`lexicon.gd` 的 `BAG_SIZE`（6）、`BAGS_PER_ROUND`（5）、`RARE_SHARE`（奇术概率 15%）；五个叠层状态在词库里权重各 4（比别的进阶词更常出现，让蓄爆/灼烧流有机会成型）。

**句子语言的最新改动（目标、数值、括号）**
- **没有“全部”和“每个”了**：想作用于几个目标，就写几个“一个”：`选择 一个 敌方 随从` 选 1 个，`选择 一个 一个 敌方 随从` 选 2 个不同的目标，最多 4 个；候选不够时多出来的“一个”不用选。第一个“一个”免费，每多一个加 2 点价格。监听范围（`当 选择 一个 一个 友方 随从 …`）同样。
- **统计人数**：`敌方人数`、`友方人数`（一张词，进阶、价格 2）。
- **数值运算**：`加上`、`减去`（进阶、价格 1，中缀，从左到右算，减不到 0 以下，一个数值式最多 6 项，取代原来的“合计”）；`较高者 / 较低者 / 差值` 仍是前缀写法。**括号**（`（` `）`）是免费的连接牌，可以不用；用了就先算括号里的。
- **数值里的“选择 一个”**也会在宣告时让你点人（例如 `造成 选择 一个 友方 随从 当前生命 伤害`）。
- **打断和沉默都取消了**（旧的狂振/牵连/升华/护盾/易伤也一起废弃，换成五个叠层状态）。
- 冒险课程换成了新的 20 关（见上），旧的通关记录会清掉。

**同一秒的结算顺序（最新）**：同一秒里的效果按顺序一件一件算，先手方的行动先算；血量降到 0 的那一刻就倒下，之后同一秒的治疗救不回来（【不屈】仍可保命一次）；治疗最多补到生命上限，溢出不能抵消伤害。【转为 恢复生命】改成“伤害先落下、随后返还等量治疗”，整句话共用一份上限（谁先挨打算谁的），致命伤直接倒下。

**挑兜子辅助轮**：每次挑兜子时，小词按“你现有的词 + 这一袋”给每袋三条备选（激进进攻 / 稳健防御或反制 / 沉默延后），写明怎么拼（词的顺序）和针对对手已亮出的牌什么（首挡 → 多段攻击；治疗护盾 → 打断沉默；埋伏 → 驱散；血少的卡 → 斩杀等），并推荐选哪一袋（`coach.gd::draft_plan`，界面 `draft_screen.gd`，`--demo=draft2`）。

**回合讲解**：每轮结算后，小词挑一个最影响战局的互动（突破首挡、打断、落空、倒下得分）讲因果并让相关随从闪一下（`battle_screen.gd::_coach_round`，与“辅助轮”开关同一个设置）。双方都没出手的空回合不会在空时间轴上等待。

**胜负规则**：每轮全部结算后，若至少一方达到 150 分，分数较高者获胜；同分则继续；最多 12 轮，第 12 轮结束分高者胜、同分平局。

标题画面的「新手教学」从头教起（约 10 分钟，57 步）：认识随从卡 → 拼第一个招式（只给最简单的词）→ 亲手打碎稻草人 → 抽词 → 调整（把减伤套在队友头上）→ 稻草人还手时用时间点防守 → 一轮多个行动。每一步只讲一件事，做对了才进下一步；文案在 `data/tutorial.json`。

讲解由桌宠“小词”的气泡说出。教学之外，小词会：

- 在你拼技能时感叹一句：“你这个技能将会……，然后……，预计……！”，遇到厉害或很贵的技能会惊叹；
- 在你准备出招时说出这招的预计效果（假设对手不还手）；
- 对手宣告后提醒你“第几秒、谁要打你的谁、多少”；
- 击倒、被击倒时欢呼或难过。

小词可以拖动，点一下会再说一遍；标题画面有「桌宠：开/关」。

## 强度回执与出招预判

- **强度回执**（编辑器里）：这招放到当前牌桌上预计能打倒谁、打多少；对手**公开的牌组**里有没有能拆它的招；它怕什么（起手时间、多大力度的打断/沉默能压住、对手公开的关键词）。
- **出招预判**（战斗里，辅助轮）：费用公式、预计效果、怕什么；后手看到的对手行动只列事实，不替你模拟交锋。

## 战斗画面

- 宣告时镜头转到**俯视 5 对 5**（像炉石），随从拉开间距、每个随从脚前有清晰的铭牌（名字、血条、状态）；完成宣告后转回第一人称看结算。
- 已宣告的行动在桌上画成**意图箭头**：从出手者指向目标，标着“第几秒 −多少”（对手红、自己蓝；设伏、打断等标在头顶）。
- 手牌按随从分组：框顶是谁，框里是它的技能；选中时桌上对应的随从脚下亮绿圈。
- 打击感：大伤害震屏、击倒顿帧 + 大字 + 分数飞向比分牌、连续触发显示“连锁 ×N”。全部参数在 `data/fx.json`。
- 每个随从**一个技能**（技能里可以用“并”连多个效果）。

## 电脑对手

按“性格”（狂攻 / 守反 / 控场 / 连锁 / 均衡）构筑牌组、挑词袋；战斗里**逐个模拟**自己所有合法行动（每个目标、每个起手时刻），后手能看见你的宣告后再选最好的应对，先手会预判你的若干应对。它只用公开信息。

## 目录

```
project.godot
scenes/main.tscn            入口场景（只挂一个脚本）
data/words.tsv              词库（id 词 类别 稀有度 价格 已实现 权重 含义）
scripts/core/
  lexicon.gd                词库、词袋、开局词
  grammar.gd                技能节点树：所需词、费用、合法性、人话描述
  engine.gd                 结算引擎（纯规则，不含界面与发牌）
  recipes.gd                21 个招式模板（简单编辑器与 AI 共用）
  deck.gd                   牌组、预算与词的校验
scripts/game/match.gd       一局的流程（抽词、调整、宣告、结算），与界面无关
scripts/ai/ai.gd            电脑对手
scripts/ui/                 界面：标题、构筑、抽词、战斗、两个编辑器、组件
tests/                      测试与审计（见下）
```

**引擎与界面完全分离**：`core/` 和 `game/` 不引用任何界面，`tests/` 里的脚本可以无窗口批量跑；以后换界面或做联机，只需要调用 `match.gd` 与 `engine.gd`。

## 数字牌模式（新玩法，和上面的对局是两套规则）

标题页「数字牌模式（新玩法 · 试玩）」进入。代码全部在 `scripts/numcard/`（规则 `nc_rules.gd`、结算 `nc_engine.gd`、一局流程 `nc_match.gd`、电脑 `nc_ai.gd`、人话 `nc_text.gd`、界面 `ui/`），不改老模式的任何规则。

- 数字是牌：1 免费无限用；2~5 从职业阶梯解锁（得分到 10%/25%/45%/70% 各两张，能反复用，用完冷却一轮）；一轮里掉 4 点以上血或有随从倒下，掷两个骰子，掷出几给一张几（一次性）。
- 数字就是次数：选几个目标、打几点、回几点、减几点、重复几次、持续几轮、延后几秒，都用数字牌，每个位置一张。
- 五个职业各自得分：进攻（伤害）35、守护（挡掉/转走的伤害）18、积蓄（状态兑现的效果）38、治疗（回血，自残再奶也算）35、控制（让对方白花的行动点）25；击倒一个敌人 = 目标分的 15%；先到 100% 的赢，12 轮打满比百分比。
- 轮流宣告：先宣告的一方每轮轮换，一次定一个随从的一句，看得见对方已经定下的句子。
- 行动点开局 6、每轮 +6、上限 12；一句 = 1 + 进阶词价格 + 每多一段（并）2；最多三段；最早第（1 + 进阶词数 + 段数 − 1）秒起效。
- 组卡：15 张进阶词（易伤、灼烧、衰弱、蓄力、铁壁、回敬、转移、延后、移除），同名最多 2 张，另选 3 个关键词（首挡/不屈）；每个职业有推荐卡组，只当建议。
- 数值来自 `设计与审计/数字牌模式/nc_sim.py` 的十轮迭代（职业胜率 44%~54%，先宣告方约 50%，平均 8.6 轮）。
- 测试：`tests/t_nc.gd`（电脑对电脑批量）、`tests/t_nc_ui.gd`（界面通关）、`tests/t_nc_shot.gd`（截图）。
- 已知问题：玩家打得很被动时，治疗、控制这类电脑职业也很难得分（数字牌靠得分和挫折才拿得到），局可能拖满 12 轮；蓄力、易伤用得很少（续暴研究还在做）。

## 已知限制（没做或没做好）

- 只有单人对电脑，没有联机；没有美术与音频素材（图形、音效都由代码生成，素材接口见 `docs/素材与特效接口.md`）。
- 「借用」（复制对手已宣告的技能）等新想法还没做。
- 电脑不会“读人”：它按模拟结果选，不猜你的下一步；构筑相对朴素。
- 平衡：见 `docs/调参记录.md`。纯防反牌组偏弱，电脑几乎不会用蓄力（我手工拼的蓄爆牌组对电脑默认牌组约 53%～68%）；全部是电脑对电脑 / 电脑对手工牌组的数据，没有真人玩过。
- **词与兜子**：基础词无限供应；进阶词只能靠挑兜子拿（每轮 5 个兜子、每个 6 词，上一轮先手先挑）。数值是第一轮自测的结果，见 `docs/调参记录.md`；还没有真人玩过。
- 窗口尺寸按 1600×900 设计，其它分辨率用拉伸适配，没有专门做小屏布局。

## 3D 牌桌与模块化外观

战斗界面默认是 3D 牌桌：你第一人称坐在桌前，对手坐在对面，随从站在桌上，行动点是右侧的筹码堆（每 15 点一枚）。`--2d` 启动参数可回到 2D 排布。

- 动画与移动全部由代码驱动（前冲、后仰、抖动、闪光、光弹、换位滑动、倒下/复出、筹码落下）。
- 随从外观由 `data/appearance.json` 的规则决定：关键词/词语/节点/标签 → 挂点（`Socket_<slot>`）上的配件，体型随生命变化。
- 素材接口：模型、特效、音效、桌宠、图标、牌桌都能直接放文件替换，不改代码；缺失时自动使用代码占位。完整约定见 **`docs/素材与特效接口.md`**。
