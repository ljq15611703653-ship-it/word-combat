# 数字牌模式 · 故事与分镜 使用说明

新故事「余烬」：起义军少年叶栖潜入义体公司「言枢」，14 次“模拟实验”实为打自己人。旧故事（零/阿词/句号/小剑）已全部废弃。

## 文件清单
| 文件 | 内容 |
|---|---|
| 00_风格圣经.md | 画风、色板、分镜语言、GPT 提示词模板与一致性做法 |
| 01_世界观与人物.md | 世界观、主角小队、起义军四队、公司人物 |
| 02_主线大纲.md | 序章 + 14 关 + 揭示 + 劝降 + 选择 + 三结局 |
| 03_角色设定表提示词.md | 21 个角色各 4 张图的提示词 + 7 张小队合照 + 面具设定 |
| 04_场景与道具提示词.md | 15 个场景、10 个道具 |
| 05_分镜_序章/第一章/第二章/第三章/第四章/终章.md | 113 格分镜，每格含可复制英文提示词 |
| 06_关卡对话.json | 14 关游戏内对话（intro/outro/hints，intro/outro ≤ 40 字，rounds ≤ 30 字，含 expr/side） |
| 07_panels.json | 引擎播放用分镜清单，与 05 id 一一对应 |

## 怎么用
1. **先出设定图**：按 `03` 为每个角色生成「全身正面设定图」，选定后命名 `sheet_<角色拼音>.png`；再出面具通用图、小队合照。
2. **再出场景定调图**：`04` 里的场景/道具。
3. **按分镜生成**：每格打开对应 `05_分镜_*.md`，复制「提示词」，同一次对话附上该格出镜角色的设定图 + 一句 “Use the attached character sheets as strict visual references; keep faces, hair, costume and colours identical.”
4. **命名**：生成的图存为 `<id>.png`（如 `P1-03.png`、`PA-02.png`），放进引擎的图片目录，与 `07_panels.json` 里的 `image` 字段对应。
5. 画面不含文字，台词/音效由游戏按 `07` 叠加。

## id 规则
`P0-xx` 序章；`P<关>-xx` 每关（01~03 关前，04~06 关后；第 14 关 4+4）；`PR-xx` 揭示与劝降；`PA-xx` 结局 A；`PB-xx` 结局 B。`07` 中揭示与结局的 `level` 记为 14，并带 `section` 字段（reveal/ending_A/ending_B），`when` 为 post；序章 `level` 为 0。

## 设计说明
- 对手混编：第 1~9 关用十二个起义军成员的混编面具队，让玩家前期当“模拟体”；第 10~13 关面具裂开，按并/续/择/血四流分别出场；第 14 关是叶晴、宋伯、阿豆。
- 咬合：词位=叶栖，数位=小满，引用位=柯谦；小满“一，免费”，柯谦把重要的事写在书页背面；过载=义体过载；断联=灰白线框+丢记忆。
- 同伴细节：红线、敲手腕、荔枝糖纸、硬币、艾草香、缺指义手是暗示的主要载体。

## 自查结果
- 07_panels.json 合法 JSON，113 格，id 唯一，与 05 全部一一对应。
- 14 关全覆盖，每关 6 格（第 14 关 8 格），序章 10 格，揭示 8 格，结局 A 4 格、B 5 格。
- 06 共 14 关，每关有 intro/outro/hints，台词均 ≤ 40 字。
- 每关均有暗示；并/续/择/血四个小队均出场（第 10~13 关）。
- 提示词不含任何作品名、角色名、画师名；角色描述块由脚本原样插入，因此跨格一致。
- 未改动任何代码文件，所有文件只写在 D 盘。

## 播放流程（已按用户确认调整）
每关：**关前漫画组（when=pre）→ 关卡进行，中间用视觉小说式底部对话框（角色半身立绘站左/右 + 底部文字框）→ 关后漫画组（when=post）**。漫画只在每关开头和结尾，中间不再配漫画格；`07_panels.json` 里每关只有 pre/post 两组。序章为 pre，揭示与结局为 post（带 section 字段）。

对话框数据在 `06_关卡对话.json`：`intro/outro`（进出关对话）、`rounds`（每关 1~2 轮：`say` 为该轮开始前，`after` 为该轮结算后，每条 ≤30 字，承载暗示）、`hints`（暗示备忘，供回看）。每条台词含 `who/text/expr/side`。

### 表情词表（固定 6 个，与 03 设定表「表情集」六格顺序一致）
`neutral`（平静）、`smile`（笑）、`angry`（怒）、`shock`（惊）、`sad`（悲）、`smirk`（坏笑/嘲讽）。每个角色按此顺序画六张半身表情。
### 站位
叶栖固定 left；其余所有角色固定 right（小满、柯谦、公司人物、对手各自出场时站右）。
