## 0. 一句话说清楚

**词牌就是弹药。** 宣告时拼好的那句话，在出手那一秒从随从头顶的"句牌"上一张张弹出去，飞向目标，在目标身上变成伤害、治疗、护盾、状态；演完以后，词牌按职业的方式回来（插回去、留在场上、熄灭、被吸收）。

**形状说效果，颜色和动作说职业。** 打人永远是"尖的、冲击的"，治疗永远是"上升的、柔的"，减伤永远是"挡在前面的板"，玩家看形状就知道发生了什么；而这一下是**谁的风格**——义体咔咔拼装、钟环嘀嗒回响、准星锁定、血墨泼洒——看颜色、材质、节奏和声音。

## 1. 全局规则

### 1.1 词牌实体

| 项目 | 规格 |
|---|---|
| 普通词牌 | 0.075 × 0.075 × 0.012 的小方块，倒角 0.004；正面是词（思源黑体，白/象牙白字），背面是职业材质 |
| 数字牌（2~5） | 稍大稍厚：0.085 × 0.085 × 0.016；正面一个大号亮黄数字 `#FFD21F`，带深色描边；侧边有"牌缘"花纹表示来源（见 1.5） |
| 数字 1 | 不是牌，是一枚更小的素片 0.055 见方，灰白 `#CFC6B8`，没有牌缘，表示"免费" |
| "并" | 普通词牌规格，但每个职业都会把它做成特殊形态（关节、齿轮、透镜旁的分隔环、血线结） |
| 句牌 | 宣告后悬在出手随从头顶 0.42 处的一块横条，上面嵌着这句话的全部词牌，平时半透明（不透明度 0.35），出手时变实 |
| 敌我区分 | **我方**词牌描一圈亮黄细边 `#FFD21F`（0.002）；**对手**词牌描酒红细边 `#8C1C2C`。镜像对局（同职业对打）时靠这圈边和飞行方向（我方的词往远处飞、对手的词朝镜头飞）分清 |

美术方向沿用全局"黑 / 红宝石暗红 / 亮黄点睛"：**桌子、界面、句牌底色都不变**；职业色只出现在**词牌背面、拖尾、冲击光和场上残留标记**上。全局禁用紫色和金色渐变——下面各职业的配色都避开了紫色；亮黄只用于数字、铆钉、指示灯这类点睛。

### 1.2 一句话的特效时间线

每句话出手，按五个阶段播放。每个职业对每个阶段都有自己的版本（见各职业章节）。

| 阶段 | 名称 | 默认时长 | 做什么 |
|---|---|---|---|
| A | 起句 | 0~150 | 句牌从随从头顶升起 0.12，翻成正对镜头；字幕条亮起这句话的人话；出手随从做前冲（`lunge`）的预备动作 |
| B | 出膛 / 组装 | 150~600（职业不同差很多） | 词牌从句牌上弹出，按职业方式组合（并流拼义体、续流排表盘、择流开镜、血流付血灌墨） |
| C | 逐段执行 | 每段 450~800 | 按句子里的**顺序**，一段一段播；段与段之间留 80 的间隔，让眼睛跟得上 |
| D | 结算数字 | 跟在每段命中之后 | 数字弹出、分数飞向职业进度条 |
| E | 收束 | 300~450 | 词牌回到句牌插槽（并流），或留在场上（续流的续环），或熄灭（择流），或被吸进目标/桌面（血流）；句牌降回半透明 |

**顺序铁律**：一句话里有多个效果，严格按句子顺序依次演；**上一段的命中数字没弹出来之前，下一段不开始**。同一段里打多个目标，可以错开 70~90 一个个打，但算同一段。

### 1.3 效果形状语法（全职业通用）

| 效果 | 通用形状 | 通用数字 | 命中通用反馈 |
|---|---|---|---|
| 造成伤害 | 尖的、楔形、冲击环、碎屑向外 | "−3"，暖白字 + 深红描边 | 顿帧、震屏、目标后仰（`recoil`）、血条掉 |
| 恢复 | 光点向上、柔和的光晕、十字/叶形 | "+2"，薄荷 `#7DFFC0` 字 + 深绿描边 | 无顿帧、无震屏，目标轻轻上浮 0.01 |
| 减伤 | 挡在目标**朝敌一侧**的板/面 | "每次 −2"，象牙白字 | 板子展开时一声"咔"；之后本轮每挡一次闪一下 |
| 易伤 | 目标身上出现**裂纹** | 状态图标 + 等级 | 裂纹残留（本轮淡显） |
| 灼烧 | 目标脚下一圈**火/余烬** | 状态图标 + 等级 | 轮末再烧一次（见 1.10） |
| 衰弱 | 目标武器/手部**变暗、往下坠**的重物或锁 | 状态图标 + 等级 | 目标待机呼吸变慢 |
| 转移 | **镜面/回路**，箭头折返 | 先挂上，触发时"转移 3" | 两段式：挂上一次，被打时触发一次 |
| 延后 | **时间轴上的钉子被往右推** | "推后 2 秒" | 时间轴 UI 同步移动 |
| 移除 | 保护层被**剥下、撕掉、洗掉** | "拆除：减伤、转移、续" | 掉下来的碎片落到桌面 |
| 击倒 | 冻结、褪色、倒下 | 大字（沿用 `fx.json` 的 `kill`） | 顿帧 130，震屏 0.03 |

职业只能改**这个形状长什么材质、怎么动、什么颜色、什么声音**，不能把形状语法改掉（比如血流的治疗也必须是向上的柔光，只是带着血墨的暖色）。

### 1.4 人话字幕（可读性第一条）

- 出手时，屏幕下方居中出现一条字幕条（宽度最多屏宽 70%，深色半透明底 `#0B0607` 不透明度 0.8，亮黄细边）：
  `② 剑卫 · 第 4 秒：对 2 个敌人造成 3 伤害，重复 2 次；并 施加易伤 2；并 自己减伤 2`
- 字幕按**段**切开，正在播的那段字变亮、底下一道亮黄下划线从左扫到右（扫完时长 = 这段时长）；播完的段变暗到 60%；**落空**的段加删除线、变灰 `#6B5F63`，后面跟一个小字"落空：目标已倒"。
- 段号用圆圈数字（沿用代码里的 ①②③…），和时间轴、日志一致。
- 数字在字幕里加粗，和场上的数字牌同色（亮黄）。
- 字幕在句子收束后再停 400 才淡出；同一秒连着下一句，字幕直接替换（向上滑出 120，新字幕从下滑入 120）。

### 1.5 数字牌怎么演

数字牌是这套特效里**最重要的可读信息**，所以每张数字牌都要"盖章"。

1. **烙印**：某段生效的那一刻，这段里的数字牌翻成正对镜头，亮黄数字闪亮（亮度 1→2.5→1，160），下面打一个小冲击环（复用 `stamp.tscn` 的光环、亮点、放射线），音效"铛"——数字越大，音调越低、越厚（2 = 高音、5 = 最低最重）。
2. **"选择 N"**：数字牌一分为 N，每个分身跟着一个目标飞，落在目标头顶当作"你是第几个"的小牌（显示 1/2、2/2），命中后消失。
3. **伤害/治疗/减伤的数值 N**：数字牌贴在这一段的"武器"上（每个职业的武器不一样），命中时数字从牌上脱出变成飘字。
4. **"重复 N"**：数字牌变成计数器。每打一下，计数器跳一次：`×1 → ×2 → ×3`；每一下都是一次完整的小命中（见 1.7 的压缩规则）。最后一下比前面大一号（顿帧 ×1.5、震屏 ×1.3），表示"打完了"。
5. **"持续 N"**：数字牌化成 N 个小刻度。续流挂在场上（见 4），其他职业只出现在状态图标下面一排小刻点。
6. **"延后 N 秒"**：数字牌化成 N 下"拨针/推钉"，每推一秒响一下"嗒"，时间轴上的钉子跟着一格一格走。
7. **来源花纹**（数字牌侧边）：
   - **职业阶梯牌**：侧边嵌一条职业主色的细线，用后冷却，回到手里时变黑牌（和界面一致）。
   - **挫折骰子牌**：牌角有骰子点；**一次性**，烙印后整张牌化成灰从边缘烧掉（灰烬色 `#6E5A48`，300）。
   - **保底数字牌**：素钢色侧边 `#8E949A`，没有花纹。
   - **1**：素片，不烙印，只轻轻一闪（避免满屏都是"1"的盖章）。

### 1.6 伤害数字的拆解显示

引擎会算"先加（易伤）再减（衰弱、减伤（含血契护体）、首挡、转移）"。为了让人看懂为什么是这个数：

- 命中瞬间先出**大数字**（最终伤害），字号 1080p 下不小于 34 像素。
- 同时在大数字右侧弹出一串**小筹码**，停留 220 后并入大数字：加成用红色小筹码"易伤 +1"，减免用灰色小筹码"减伤 −2""首挡 −3"。
- 打成 0 的命中：大数字显示灰色"0"，目标身上的护盾/板子闪一下，不顿帧、不震屏。

### 1.7 时长预算、压缩与快进

| 项目 | 上限（1 倍速） |
|---|---|
| 普通一句（1~3 段） | 3200 |
| 并流长句（4~5 段及以上） | 4000（并流的招牌时刻，允许多 800） |
| 续流"回响"（续环到点自动再放） | 700 |
| 一轮结算全部回放 | 目标 20 秒以内；超过时整轮自动按 1.25 倍播 |

**压缩顺序**（一句话算出来超过上限时，依次用，直到够了为止）：

1. 段间隔 80 → 40。
2. 每段时长整体乘系数，最低乘到 0.6。
3. "重复 N"里第 2 下到倒数第 2 下改成快打（间隔 70，只出数字不出完整特效），首尾两下保持完整。
4. 多目标同时打（不再错开）。
5. 组装阶段（B）最低压到 60%；并流的"咔咔"至少保留每个关节一声。

**玩家控制**：

- **2 倍速**：所有时长减半，但顿帧最少保留 30，数字最少显示 300。
- **按住加速**：按住空格/长按屏幕时 3 倍速，松开恢复。
- **跳过**：只放字幕 + 数字 + 血条变化，每个事件 150；击倒仍然出大字（300）。
- **设置项**：镜头运动开/关、闪光减弱（全屏闪光不透明度上限 0.35、震屏 ×0.3）、伤害数字常驻。

### 1.8 镜头

- 结算用"坐在桌前"视角（`seat`），宣告用俯视（`top`）。词飞行特效按 `seat` 视角设计。
- **一句话最多一次镜头运动**：默认是向目标推近，视角变窄 4%~6%，推入 250（缓入缓出 `TRANS_SINE`），保持到最后一段结束，退回 300。
- 镜头不切、不转超过 4°、不跟着词牌飞（防晕）。
- 击倒时额外推近到 10%，保持 400。
- 职业特例：并流 4 段以上**拉远** 8%（看全义体）；择流不推镜头，改成画面四角暗角（瞄准镜感）；血流付血时镜头轻轻下压 2°（沉重）。
- 震屏沿用 `fx.json` 的写法 `[幅度, 秒]`，幅度单位和现有一致（普通命中 0.004，大伤害 0.012，击倒 0.03）；各职业只乘倍率。

### 1.9 同一秒好几句一起出手

- 引擎同一秒里有先后顺序（按结算顺序）。特效**也按这个顺序**播，不并行播命中。
- 允许**交叠**：后一句的 A、B 阶段（起句、组装）可以和前一句的 E 阶段（收束）重叠，最多重叠 300；但后一句的第一次命中，必须在前一句最后一个数字弹出之后。
- 同一秒的句子，时间轴上那一秒的格子显示"同秒 ×2"，字幕条左边加一个小角标"同秒 1/2"。
- 同一秒里如果前一句把后一句的出手随从打倒了，后一句直接演"整句落空"（1.10）。
- 续流的"回响"和普通句子同一秒时，回响先放（它短，而且是上一轮就定好的）。
- 两句打同一个目标：第二句的冲击特效缩小到 85%，避免叠成一团；数字向上错开 0.04。

### 1.10 落空、延后、被拆的通用样子

**整句落空**（出手随从在出手前被打倒、或被延后推出第 10 秒）：

- 0~100：句牌抖两下（左右 0.006，50 一次），所有词牌变灰 `#6B5F63`。
- 100~350：句牌从中间裂开（一道白线），词牌像没粘牢一样一张张掉到桌面上，落地弹一下（`TRANS_BOUNCE`），声音是轻的木牌碰桌"嗒嗒嗒"（`word_fizzle`）。
- 350~700：桌上的词牌淡出；字幕条整条删除线，后面写"落空：出手的随从已倒下"或"落空：被推出了时间"。
- 每个职业在这里加一点自己的味道（见各章"落空"）。

**被推出时间**（延后把句子推过第 10 秒）：时间轴上那颗钉子被推到右边界外，掉下去；3D 里对应随从头顶的句牌往桌外滑 0.1、往下沉，然后按"整句落空"碎掉。

**单段落空**（这一段的目标已经不在了，且不是择流）：词牌照常飞，到了空位置失去力气，翻滚着掉下去，落地处盖一个灰色"落空"小章，字幕这一段加删除线。后面的段继续演。

**轮末灼烧**：每轮结算结束、回合总结之前，所有带灼烧的随从**同时**跳一次火（300），数字一起弹出；火的颜色用**施加者职业**的灼烧色（状态记住是谁上的）。

**关键词触发**（属于防守方，不属于出手方，所以全职业通用）：
- 首挡：目标面前闪出一块盾（复用 `block.tscn`），数字筹码"首挡 −3"，声音 `block`。
- 不屈：目标血条掉到 1 时停住，一圈亮黄光从脚底往上扫（250），飘字"不屈"，声音一记低沉的"嗡"。

### 1.11 声音总则

- 每个职业一套"声音质感"（金属伺服 / 钟表与钟 / 光学与静电 / 心跳与鼓），所有效果都用这个质感做，但**效果类型的节奏型统一**：伤害是短促重击、治疗是上行的和弦、减伤是一记"咔"加持续低鸣、状态是一个下行短音型、控制（延后/移除）是"拉扯"类的摩擦声。
- 音量层级：击倒 > 大伤害 > 数字烙印 > 普通命中 > 组装细节 > 环境残留（续环的嘀嗒、护盾低鸣，-18 dB 以下）。
- 同一秒多句时，后一句的组装声压低 6 dB。
- 新增音效名一律带职业前缀（见附录 8.4），放进 `assets/sfx/` 即替换。

### 1.12 可读性总则

1. 同一时刻只有**一个**主目标被高亮（轮廓光）。
2. 数字永远比粒子大、比粒子亮、在粒子前面。
3. 场上残留的东西（续环、减伤板、状态裂纹）平时不透明度 ≤ 0.3；只有在它起作用的那一下亮起来。
4. 一个随从身上同时显示的残留特效最多 3 个，再多的只在铭牌上用图标表示。
5. 全屏闪光一句话最多一次（击倒或并流 5 段成型）。
6. 任何特效不能挡住血条和铭牌（铭牌是 2D 的，永远在最上层）。

## 2. 无职业默认样式（第五槽占位）

给"还没选职业""电脑练习对手""未来的第五个职业"用，也是所有职业的基础模板——各职业的参数都是在它上面改。

| 项目 | 设定 |
|---|---|
| 主色 | 象牙白 `#EFE6D2` |
| 次色 | 酒红 `#8C1C2C`（拖尾） |
| 点睛 | 亮黄 `#FFD21F` |
| 材质 | 词牌背面是哑光象牙，无花纹 |
| 动作 | 普通抛物线飞行，弧高 0.08，速度 2.2 单位/秒，`TRANS_CUBIC` 缓出 |
| 声音 | 现有的 `cast`、`hit`、`heal`、`block` |

- 起句：沿用现有 `cast.tscn`（符文蓄力后释放），亮黄。
- 出膛：词牌按顺序依次弹出，间隔 40，每张在空中排成一列。
- 伤害：一列词牌像一串弹丸飞过去，第一张撞上目标时出 `hit.tscn`（或伤害 ≥10 时 `big_hit.tscn`），其余词牌在撞击点碎成亮黄小星。
- 恢复：词牌飞到友方头顶，化成光点落下，`heal.tscn`。
- 减伤：词牌在目标前排成一面板，`shield.tscn`。
- 状态：词牌贴在目标身上化成图标。
- 转移 / 延后 / 移除：`trigger.tscn` / `interrupt.tscn` / `interrupt.tscn`。
- 击倒：`kill.tscn`。
- 收束：剩下的词牌淡出，句牌降回。

## 3. 并流 · 义体

> 一句话："句子是一条机械臂，'并'是关节。" 词飞出去，咔咔咔拼成一条赛博朋克义体，一节一节地打出去，打完拆开，飞回句牌插槽。

### 3.1 视觉身份

| 项目 | 设定 |
|---|---|
| 主色 | 电光青 `#2DE2FF`（电路纹、关节缝光、拖尾） |
| 次色 | 铬银 `#C9D3DC`（金属面），暗部枪灰 `#3A4148` |
| 热量色 | 警示橙 `#FF6A1A`（打桩拳过热、刻蚀针、灼烧） |
| 点睛 | 亮黄 `#FFD21F`（铆钉、指示灯、数字） |
| 背光 | 深海黑 `#071820`（冲击波内圈的暗部） |
| 词牌材质 | 背面拉丝金属，青色电路纹自发光（强度 2.0），边缘倒角反光；正面字带极轻的扫描线 |
| "并"的形态 | **球形关节**：一颗六角螺母 + 一圈会转的伺服环，缝隙透青光；空闲时伺服环以 720°/秒转 |
| 动作语言 | **伺服步进**：移动不走顺滑曲线，而是 2~3 步完成，每步之间停 30（机械的"一顿一顿"）；旋转按 15° 一格卡；直线、快、硬停（移动 `TRANS_EXPO` 缓出，卡合 `TRANS_BACK` 缓出带轻微过冲） |
| 声音质感 | 伺服电机的上行"嗞——"，金属卡扣"咔"（两层：清脆的扣 + 低沉的"咚"），液压泄气"嘶"，合成器低音的打击，数据"滴滴" |
| 得分反馈 | 每个关节上有一颗指示灯：这一段**兑现**（打中/生效）时灯从青变亮黄；义体根部有一块小屏"兑现 3/4" |

**义体随段数长大**：

| 段数 | 形态 |
|---|---|
| 1 段（没有"并"） | 腕刃：一节，直接装在手上 |
| 2 段 | 前臂：一个肘关节 |
| 3 段 | 整条手臂：肘 + 肩 |
| 4 段 | 整条手臂 + 背上展开一条副臂 |
| 5 段及以上 | 双臂 + 背后链式长臂（"全义体"），镜头拉远 8%，触发一次全屏青色电路描边 |

**每一段的"工具头"**（由这一段的效果决定，装在这一节的末端）：

| 段的效果 | 工具头 |
|---|---|
| 造成伤害 | 打桩拳（带活塞，打之前会过热发橙） |
| 恢复 | 纳米注射器（透明针筒，青绿色药液 `#7DFFD8`） |
| 减伤 | 折叠装甲（六角板叠在一起） |
| 施加状态 | 刻蚀探针（细针 + 一枚状态芯片） |
| 转移 | 偏转镜面板 + 一根数据线插头 |
| 延后 | 齿轮夹钳 |
| 移除 | 液压破拆剪 |

### 3.2 招牌时刻：并 · 组装（A + B 阶段）

以 N 段、N−1 个"并"为例。

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~60 | 句牌从随从头顶升起 0.12，一道青色扫描线从上到下扫过句牌 | 数据"滴" |
| 60~260 | **退弹**：所有词牌同时从句牌里弹出，每张间隔 8，垂直弹出 0.06，然后转 90° 侧立（像弹匣里的子弹被拨出来）；"并"牌掉到中线上，伺服环开始高速转，冒出细小青色电弧 | 一串很快的"嗒嗒嗒" + 伺服上行音 |
| 260~(260+110×(N−1)) | **咔咔咔**：从第一个"并"开始，每 110 处理一个关节——左右两段的词牌先各自叠成一节"臂节"（动词词牌变成工具头，数字牌插在侧面像弹匣指示器，露出数字），然后两节同时向关节冲过去（90，`TRANS_EXPO` 缓入），碰上的瞬间：顿帧 25，关节迸出 4 颗亮黄火花，伺服环从白闪回青，微震屏 0.002/60，关节指示灯亮起（青） | 每个关节一声"咔"，音高逐个升高半音（咔、咔、咔↑） |
| 接着 120 | **成型**：整条义体一下拉直，一道青色脉冲从根部跑到尖端（120），每个关节喷出一小团白汽 `#EAF6FF`（不透明度 0.5，上飘 0.05 消散） | 液压"嘶——" |
| 接着 80 | **接驳**：义体根部飞向出手随从的右肩挂点（`Socket_shoulder_r`），卡上，随从身体顺着闪一圈青边 | 一声低沉的"咚" |

- 5 段及以上：成型时额外加一次全屏边缘青色电路描边（不透明度 0.3，200 淡出），复用 `reveal_rays_soft_1024.png` 做背后的放射光，`chain.tscn` 以 `n = 段数` 在随从脚下播。
- 只有 1 段（没有"并"）：跳过"咔咔"，词牌直接叠成腕刃装到手上，B 阶段只要 150。

**执行时的"转关节"**：轮到第 k 段时，第 k 个关节以 15° 一格的步进转动（2 步，每步 40），让第 k 节的工具头对准目标，然后出手。上一段的工具头会收起（折叠 60）。

### 3.3 造成伤害

**单目标**（例：造成 3 伤害）

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~80 | 关节步进转向目标；打桩拳活塞开始发橙 `#FF6A1A`（自发光 0→1.5）；侧面的数字牌翻出"3" | 伺服"嗞" + 过热的电流声 |
| 80~200 | 这一节伸缩臂往目标弹出 0.25（`TRANS_EXPO` 缓入），身后拖出两条平行的青色轨道线（像导轨，宽 0.003，长度跟随，150 后消失） | 风切"咻" |
| 200 | **命中**：顿帧 40（伤害每多 1 点 +10，最多 90）；复用 `hit.tscn`，`color = #2DE2FF`，外加 6 颗橙色火花；目标脚下贴一个六角网格冲击波贴花（直径 0.18，200 扩散淡出）；目标模型做 2 帧"数据错位"（横向切片错开 0.01）；震屏 0.004 + 0.0012×伤害 | 打桩"咚" + 合成器低音 |
| 200~260 | 伤害数字"−3"弹出：亮黄字、青色投影，出现时 RGB 分离 3 像素抖 60 后对齐 | 数字烙印"铛" |
| 260~360 | 活塞收回，关节喷一小团白汽，这一节的指示灯从青变亮黄（兑现） | "嘶" + "滴" |

**多目标**（例：选择 2 敌方 随从）

- 0~80：打桩拳的拳头**展开成 N 根机械指**（每根展开间隔 30，每根一声小"咔"），数字牌分身成 N 张贴在每根指上。
- 80~200：N 根指同时伸出，但从左到右每根晚 70 出发（像连发的钉枪）。
- 每根命中都是完整的单目标命中，顿帧只在第一根和最后一根做（避免卡顿）。
- 260 起：机械指收回合拢，"咔"一声。

**重复 N**（例：造成 3 伤害 重复 2）

- 打桩拳变成**风镐模式**：第 1 下完整命中；之后每下间隔 140（N ≥ 4 时 90），活塞每下都伸缩一次，每下从侧面弹出一个亮黄的小弹壳（金属叮当落到桌上，300 后淡出）。
- 侧面的数字牌变成计数器"×1 ×2 ×3"，每下一跳。
- 最后一下：活塞过热到白 `#FFF4E8`，顿帧 ×1.5，震屏 ×1.3，散热片张开喷大团白汽。
- 声音：一串"咚咚咚"，最后一下加重 + 长"嘶"。

### 3.4 恢复

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~120 | 关节转向友方；工具头是纳米注射器，针筒里青绿药液 `#7DFFD8` 发光；针头弹出 | 气压"噗" |
| 120~200 | 针头伸到友方身边（不刺入，停在 0.02 外），一条细细的青绿光束连上 | 高频"嗡" |
| 200~550 | 注射：针筒里的液面**一格一格**往下降，格数 = 治疗量（每格 60）；友方身上爬满六角形纳米颗粒（青绿，从脚往头爬，400），颗粒爬过的地方亮一下 | 每格一声上行"叮"，像和弦一个音一个音往上 |
| 550 | "+2"薄荷色数字，带青色描边；复用 `heal.tscn`，`color = #7DFFD8` | 和弦收尾 |
| 550~650 | 针头收回，关节指示灯变亮黄 | "滴" |

### 3.5 减伤

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~100 | 这一节的六角装甲板从臂节上脱开（一片片翻开，像扇子），数量 = 减伤值 | 金属片摩擦"唰" |
| 100~250 | 装甲板飞到目标**朝敌一侧** 0.08 处，按蜂窝排开，每片落位间隔 40 | 每片"咔" |
| 250~350 | 整面板子边缘亮一圈青光（`cast_def.tscn` 染青），中心浮出"每次 −2" | 低频"嗡"开始（持续音，-20 dB） |
| 之后整轮 | 板子缩成只剩青色六角轮廓（不透明度 0.25），轻微闪烁（每 1.5 秒一次） | 无 |
| 每次挡伤害时 | 被打到的那片板子闪白，整面泛一圈涟漪（复用 `shield.tscn` 染青），弹出灰色筹码"减伤 −2" | "叮" |
| 本轮结束 | 板子碎成像素方块往下掉，200 淡出 | 轻"沙" |

### 3.6 施加状态

工具头都是刻蚀探针：先飞出一枚**状态芯片**（0.02 见方的小方片）钉进目标，再各自展开。

**易伤**

- 0~120：探针瞄准，芯片发射（直线，100），芯片表面印着裂开的盾图标，橙色。
- 120：芯片钉入目标胸口，"叮"。
- 120~420：以芯片为中心，橙色 `#FF6A1A` 的电路状裂纹往外爬（像电路板走线，直角拐弯），条数 = 等级；爬完后裂纹定住、变暗到 0.3。
- 420：铭牌上出现易伤图标 + 等级。声音：芯片入肉"叮" + 下行三音"嘀嘀嘟"。

**灼烧**

- 0~150：探针前端过热到白橙，喷出一股铝热剂火花（橙白 `#FFC27A`，粒子 60 个，抛射）。
- 150~450：目标脚下出现一圈熔化的电路环（橙色线路发红，冒小火星），火星往上飘。
- 之后整轮：脚下一圈很淡的热浪扭曲（不透明度 0.2）。
- 轮末灼烧时：电路环猛地亮起，一柱橙白火花往上喷（300）。
- 声音：焊枪"嗞——"，轮末"噗哧"。

**衰弱**

- 0~120：探针刺出一枚青色"抑制码"芯片。
- 120~400：芯片钉到目标的武器/手上，展开一个青色的锁扣（把手部框住），锁扣上有 N 个向下箭头。目标身体的自发光亮度降 30%，武器下垂 5°。
- 铭牌旁出现一个小"节流表"，指针往下掉 N 格。
- 声音：断电"嘟——"下行 + 锁扣"咔"。

### 3.7 转移

两段式：**挂上**（这句话出手时）和**触发**（之后本轮有人打这个目标时）。

挂上（400）：
- 0~120：这一节的偏转镜面板展开（像折叠屏打开，两折，每折一声"咔"）。
- 120~300：镜面板飞到被保护者面前 0.1，竖立；一根数据线从镜面板背后拖出，另一头插进被保护者身后的地面（"插口"亮青光）。
- 300~400：镜面上闪过一道反光扫掠；之后镜面板缩成一块淡青色的竖线框（不透明度 0.3）。复用 `cast_trap.tscn` 染青。
- 声音：屏幕展开"咔咔" + 插头"嗒"。

触发（450）：
- 0：对手的攻击打在镜面上，镜面亮白，顿帧 40。
- 0~150：伤害化成一个青色**数据包**（发光的小方块），沿一根新生成的数据线（贝塞尔曲线，下垂 0.05）飞回攻击者，线一节一节点亮。
- 150：打在攻击者身上，`hit.tscn` 染青；数字"转移 3"。复用 `trigger.tscn` 在镜面处爆一次。
- 150~450：镜面板碎成像素消失（一次性）或保留（若规则是整轮有效，则缩回线框）。
- 声音：镜面"锵" + 数据传输"嘀哩哩哩" + 命中"咚"。

### 3.8 延后

- 0~100：工具头是齿轮夹钳，弹出，三爪张开。
- 100~250：夹钳飞到敌方那句话的句牌（在敌方随从头顶），三爪合拢夹住，"咔"。
- 250~(250+N×100)：夹钳**往后拧**，每拧一格 100：齿轮"咔哒"一声，句牌往桌外移 0.02；屏幕下方时间轴上那颗钉子同步往右跳 1 秒，跳的时候拖出青色残影。
- 拧完：夹钳松开，弹回，句牌摇晃两下稳住。字幕"把 ② 推到第 7 秒"。复用 `cast_ctl.tscn` 染青做夹住时的闪光。
- **推出第 10 秒**：最后一格时夹钳不松开，而是把句牌整块扔出桌外，句牌在空中碎成青色像素块，`interrupt.tscn` 染青；随后按"整句落空"处理。声音多一声"嘣"。

### 3.9 移除

- 0~120：液压破拆剪张开，剪刃发橙。
- 120~300：剪刀飞到目标，对准它身上的每一层保护（减伤板、转移镜面、挂着的续环……），**每层剪一下**，间隔 90：剪合拢"嘎嚓"，那一层保护变成一块金属板从目标身上掉下（带 2 颗火花，落到桌上弹一下，400 淡出）。
- 剪完：铭牌上那几个保护图标被打叉划掉，字幕"拆掉了 剑卫 的保护"。
- 目标没有任何保护：剪刀剪空，"咔嚓"一声空响，字幕这一段灰色"没有可拆的"。

### 3.10 击倒

在致命那一下命中之后接上：

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~120 | **凝帧**：整条义体保持伸出姿势定住，所有关节指示灯同时闪亮黄 | 一切声音被低通滤波压住 |
| 120~300 | **过载**：从命中点爆出一圈青色电磁脉冲环（贴桌面扩散，半径 0~0.6，`TRANS_EXPO` 缓出），扫过的桌面纹理短暂发青 | "嗡——啪" |
| 120~700 | 目标模型从上到下**碎成青色小方块**（体素化），方块往下掉、在桌面上弹一下后淡出；复用 `kill.tscn` 叠在下面 | 碎玻璃 + 数字噪音 |
| 300~700 | 大字"击倒！+分"（沿用 `fx.json`），分数从义体根部的小屏飞向比分牌 | `down` |

### 3.11 收束与落空

- **收束（E）**：所有段演完后，关节**倒序**解锁，每个 60（比组装快一倍），"咔咔咔"音高逐个降低；词牌沿直线飞回句牌上各自的插槽，每张插回去"嗒"一声 + 青色小闪；句牌两侧喷汽，降回半透明。总长约 350。
- **整句落空**：词牌掉下来之前先短路——每张词牌冒一下青色电火花，然后熄灭变灰，再按通用规则掉落。
- **单段落空**：那一节的工具头打空，关节指示灯变红 `#FF3048` 闪两下，义体其余部分照常；根部小屏显示"兑现 2/3"。

## 4. 续流 · 钟环

> 一句话："句子是一面钟，'持续'是钟摆。" 词排成表盘，秒针扫过、一下一下敲出去；带"持续"的那段会在场上留下一个铜环，之后每轮同一秒自己再响一次，直到出手的人倒下或被拆。

### 4.1 视觉身份

| 项目 | 设定 |
|---|---|
| 主色 | 琥珀 `#FFB23F` |
| 次色 | 古铜 `#B8743A`，暗部深铜褐 `#3A2410` |
| 脉冲光 | 暖黄 `#FFD98A`（顺着丝线跑的光珠） |
| 点睛 | 余烬白 `#FFF1D6`（刻度、秒针尖） |
| 断裂色 | 灰烬 `#6E5A48` |
| 词牌材质 | 背面是黄铜，边缘刻一圈钟表刻度，字发暖光 |
| "持续"的形态 | **擒纵轮 + 钟摆**：一枚小齿轮，下面挂一个摆锤 |
| "并"的形态 | 表盘上的一道小齿（相邻两段之间的分隔刻度） |
| 动作语言 | **一切都在节拍上**：以 150 为一拍（"嘀嗒"格），所有起止都对齐到拍点；走弧线和圆周，不走直线；缓入缓出 `TRANS_SINE`；摆动有钟摆的回荡（过中线最快，两端停顿） |
| 声音质感 | 擒纵"嘀嗒"、铜钟/磬的长尾音、低沉心跳、反向混响的"吸气"感 |
| 得分反馈 | 每次回响产生的数值，和状态兑现时，琥珀色小数字带"续"字小标签飞向职业进度条 |

### 4.2 起句与出膛：排表盘

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~150 | 句牌升起，翻转成一面圆形表盘（半径 0.14，正对镜头，斜 10°） | 一声"嘀" |
| 150~300 | 词牌沿圆周排开，像钟面上的时辰；"并"变成段与段之间的小齿；"持续"落到表盘正中，挂成钟摆，开始摆 | 每张词牌落位一个轻"嗒"，正好落在拍点上 |
| 300~600 | 一根余烬白的秒针从 12 点位置扫一整圈（300），扫过的词牌依次亮成琥珀色 | 秒针扫过时连续的细"嘀嘀嘀" |
| 600 | 表盘外圈亮一下，复用 `cast.tscn`，`color = #FFB23F` | 铜钟轻响"当" |

执行每一段时：秒针指向这一段的词牌，这几张词牌沿表盘**切线方向**甩出去（像弹弓，先绕表盘转 90° 加速，再脱手），走一条弧线飞向目标。

### 4.3 造成伤害

**单目标**

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~150（一拍） | 这段词牌甩出表盘，弧线飞行，身后拖一条琥珀色的圆弧光尾 | "嘀" |
| 150~300（一拍） | 词牌到目标身边，**绕目标转 1/4 圈**，同时在目标周围画出一个琥珀色圆环（半径 0.12） | "嗒" |
| 300 | **收紧**：圆环猛地收缩到目标身上（60，`TRANS_EXPO` 缓入）；命中闪光琥珀 + 余烬白；复用 `hit.tscn`，`color = #FFB23F`；顿帧 40；震屏 0.004 + 0.001×伤害 | 铜钟重击"当" |
| 300~450 | 数字"−2"弹出，琥珀描边；命中处留下一圈淡淡的同心圆涟漪向外扩散一次 | 钟声尾音 |

**多目标**：每个目标一个圆环，**所有圆环在同一拍上同时收紧**（续流的标志是同步，不是错开）；数字同时弹出，从左到右高度依次高 0.02。

**重复 N**：圆环一个接一个收紧，**严格每拍一下**（150），每下一声"嘀嗒"里的"嗒"；表盘上的秒针每下也跳一格。最后一下圆环是双层的，钟声加一个低八度。

### 4.4 恢复

- 0~150：词牌甩出，绕到友方身后。
- 150~600：以友方为中心，**向外**扩散的暖色圆环，一圈一圈，每拍一圈，圈数 = 治疗量（最多显示 5 圈）；每一圈扩散时友方身体随之"呼吸"一下（放大 1.03 再回来），就像心跳。
- 每圈一声低沉温暖的心跳"咚"，最后一圈加铜磬"嗡——"。
- 数字"+3"，薄荷字 + 琥珀描边；复用 `heal.tscn`，`color = #FFD98A`。

### 4.5 减伤

- 0~150：词牌飞到目标朝敌一侧。
- 150~300：展开成一面半透明的**表盘护罩**（圆盘，半径 0.1，铜框，琥珀玻璃），盘面上亮起 N 个时刻刻度（N = 减伤值）。
- 300：护罩边缘"当"一声定住。
- 整轮：护罩淡显（0.25），一根小指针慢慢走（每秒走一格，与时间轴同步——玩家看它就知道现在第几秒）。
- 挡伤害时：护罩亮起，指针跳一下，弹出"减伤 −2"灰筹码，声音"嘀"。复用 `shield.tscn` 染琥珀。
- 轮末：护罩的刻度一个个熄灭，护罩合拢消失。

### 4.6 施加状态

**易伤**：词牌钉在目标身上，变成一个小表心，从表心伸出 N 根"指针"状的裂纹（像钟面上的时针分针，均匀分布），裂纹是琥珀色发光的细线；之后淡到 0.3。声音：表针"咔"+ 下行音。

**灼烧**：目标脚下出现一圈**余烬刻度环**（铜色刻度，每格冒小火星），刻度数 = 等级。轮末灼烧时：刻度环像闹钟一样**响铃**——环抖动、一圈琥珀火焰往上冲（300），声音是闹钟"铃——"夹着火"噗"。

**衰弱**：目标身后出现一个**沉重的摆锤**虚影（铜色，半透明），摆锤一下下拖慢它：目标待机呼吸变慢 30%，动作出现 1 帧拖影（慢动作残影）；铭牌旁出现摆锤图标 + 等级。声音：低沉的"咚……咚……"，比正常心跳慢。

### 4.7 转移

挂上：被保护者头顶挂一个倒置的小钟摆（琥珀色），摆幅很小地晃。复用 `cast_trap.tscn` 染琥珀。

触发：
- 0：攻击打到被保护者，钟摆被"推"到最高点（定格 60）。
- 60~300：钟摆**回摆**——攻击的能量化成一团琥珀光，沿着钟摆的圆弧轨迹甩回攻击者（弧线，弧高 0.15）。
- 300：命中攻击者，`hit.tscn` 染琥珀，"转移 3"。
- 声音：钟摆"嗖——"往返 + "当"。

### 4.8 延后

续流做延后最有味道：**拨针**。
- 0~150：敌方句牌上方出现一个巨大的半透明表盘虚影（半径 0.18）。
- 150~(150+N×150)：一根琥珀色的大针**往前拨**，每拨一秒占一拍，"咔哒"；时间轴上的钉子同步往右一格一格走。
- 拨完：表盘虚影淡出（200），复用 `cast_ctl.tscn` 染琥珀。
- **推出第 10 秒**：大针拨过 12 点，表盘敲响十二下（只敲 3 下示意，越来越快），敌方句牌像沙漏流完一样从上往下化成金色细沙落下，按"整句落空"收尾。

### 4.9 移除

**停摆**：目标身上的每层保护变成一组小齿轮的样子，齿轮依次**卡住、停转**，然后像生锈一样变成灰铜色 `#6E5A48` 碎裂、掉落。每层间隔 100。声音：齿轮"咯吱"卡死 + 碎裂"咔啦"。

### 4.10 招牌时刻：续 · 挂环、残留、回响、断裂

**挂环**（带"持续 N"的那一段第一次生效之后）：

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~150 | 这一段的"持续"钟摆不跟着回去，而是从表盘中心飞出，升到出手随从头顶 0.55 | 发条上紧"咔咔咔" |
| 150~300 | 展开成**续环**：黄铜细环（半径 0.06，粗 0.006），环上有 N 个凹槽，每个凹槽亮着琥珀光点（N = 持续轮数） | 每个光点亮起"叮" |
| 300~450 | 从续环垂下一根琥珀**丝线**（粗 0.004，自然下垂的悬链线）连到这一段的目标身上；丝线上每 1.2 秒跑过一颗暖黄光珠 | 极轻的"嘀嗒"开始循环（-24 dB） |
| 450 | 屏幕下方时间轴上，**下一轮的同一秒**位置出现一个琥珀空心小圆钉，标"续" | — |

如果这一段打的是多个目标，续环下面垂多根丝线。

**残留**（轮与轮之间、宣告阶段的俯视画面）：

- 续环悬在出手随从头顶，以 20°/秒缓慢自转，剩余几轮就亮几个凹槽。
- 丝线不透明度 0.35，仍然连着目标（目标被击倒休整时，丝线垂到地上，变暗）。
- 鼠标悬停 / 长按续环，弹出说明："续：每轮第 4 秒，对 刀客 造成 2 伤害，还剩 2 轮。出手者倒下或被移除就会断。"
- **对手也看得见**——这是故意的：续环就是靶子（"攒的人被盯上"是想要的博弈）。
- 时间轴上本轮这一秒有琥珀空心钉。

**回响**（之后每轮到那一秒自动再放，总长 ≤ 700）：

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~150 | 续环"嗒"地跳一格：一个凹槽的光点从琥珀熄灭成暗铜；环下的钟摆虚影摆一下 | 清楚的一声"嗒" |
| 150~300 | 一颗明亮的光珠 `#FFD98A` 沿丝线**快速**滑向目标（150） | 上滑的"咻" |
| 300~600 | 在目标身上播这一段效果的**回声版**：和原版同一套动画，时长 70%，本体后面拖一个半透明重影（偏移 0.01、晚 60、不透明度 0.6）；顿帧减半 | 原版声音 + 一层反向混响 |
| 600~700 | 数字带小标签"续"，例如"−2 续"；同时一个琥珀小数字飞向职业进度条 | "叮" |

- **回响撞上状态**（目标身上有易伤、灼烧等）：命中时续环和目标身上的状态图标一起**共鸣**——续环外面多出一道同心环，状态图标同时跳动，声音多一层高八度的钟鸣，"状态兑现"的数字也带"续"标签飞走。
- **目标正在休整（倒下）**：光珠滑到丝线末端碰到空地，"噗"地散开，字幕"续 · 空响"，不扣轮数以外不做别的（是否扣轮数以规则为准）。
- **最后一轮的回响**：最后一个凹槽熄灭后，续环合拢成一个实心的铜圈，"当——"长鸣，然后碎成琥珀花瓣/灰烬往上飘散（600，复用 `stardust_512.png` 染琥珀），丝线从上往下化光消失。

**断裂**（出手者被击倒，或被"移除"）：

| 时间 | 画面 | 声音 |
|---|---|---|
| 0 | 续环猛地停转，定格 60 | 所有嘀嗒声突然停 |
| 60~120 | 环面上爬出白色裂纹（3~4 条） | 玻璃"咔" |
| 120~300 | 续环**崩碎**：碎成 8~12 片黄铜碎片向外飞散，凹槽里剩下的光点像火星一样四溅；复用 `interrupt.tscn` 染琥珀 | 发条崩断"嘣！" + 碎钟面 |
| 120~350 | 丝线从中间**绷断**，两端像弹簧一样往回弹、卷曲，然后变灰 `#6E5A48` 碎成粉 | 弦断"铮——" |
| 300~1100 | 碎片落到桌上，弹一下，慢慢淡出；字幕/飘字"续断" | — |
| 同时 | 时间轴上后面几轮的琥珀空心钉一起熄灭、碎掉 | — |

### 4.11 击倒

- 0~160：**时停**：顿帧 160，画面除目标外降饱和 40%。
- 160~420：一根巨大的琥珀表针以目标为圆心扫一整圈（260），扫过的地方留下一圈刻度光。
- 420~500：所有刻度光一起**塌缩**进目标身体。
- 500：铜钟"当——"重鸣，琥珀冲击波贴桌面扩散（`kill.tscn` 染琥珀叠底）；目标以 0.6 倍慢速倒下。
- 如果这一下是回响打出来的击倒：大字下面加小字"续 · 击倒"。

### 4.12 收束与落空

- **收束**：没挂成续环的词牌沿圆弧飞回表盘，表盘反向收拢成句牌（秒针倒转一圈，200），"嘀"一声降回。
- **整句落空**：表盘停摆，秒针掉下来，词牌失去光变灰，按通用规则掉落。
- **单段落空**：词牌飞到空位，绕空转一圈，像停了的钟摆一样慢慢垂下、掉落。

## 5. 择流 · 准星

> 一句话："句子是一发子弹，'选择'是瞄准镜。" 宣告时对手只看到一个乱码的"待定"准星；出手那一刻开镜、扫一遍、锁定、一枪。稳、准、安静，命中点小而亮。

### 5.1 视觉身份

| 项目 | 设定 |
|---|---|
| 主色 | 磷光黄绿 `#C6FF3D`（瞄准线、HUD、准星） |
| 次色 | 冷白 `#EAF2F0`（玻璃、弹道芯） |
| 暗部 | 墨绿黑 `#0B140A`（瞄准镜暗角） |
| 锁定点睛 | 准星红点 `#FF3048`（只用在锁定瞬间那一颗小红点上） |
| 未定色 | 噪点灰 `#8A9488`（乱码、"待定"） |
| 词牌材质 | 背面是薄玻璃 + HUD 线框，半透明（0.7），有细扫描线；字锐利，边缘有 1 像素的黄绿外发光 |
| "选择"的形态 | **瞄准镜透镜**：一个圆形镜片，十字分划 + 四个角括号 |
| "并"的形态 | 弹匣分隔片（两段之间一条细横线） |
| 动作语言 | **静 → 快**：先长时间稳住（精确），然后瞬间（≤80）直线出手；不走弧线、不过冲；括号合拢用 `TRANS_BACK` 带一点点回弹，子弹用 `TRANS_QUART` 缓入 |
| 声音质感 | 光学变焦"嗞嗞"、静电白噪、锁定"嘀、嘀、嘀——叮"、消音枪"啾"、玻璃轻碰；低频极少 |
| 得分反馈 | 每次命中显示"有效"数值（真正掉的血/真正回的血），有效值飞向职业进度条；溢出部分灰色划掉 |

### 5.2 招牌时刻（一）：宣告时的"待定"

宣告阶段（俯视），择流的句子不画指向某个随从的意图箭头，而是：

- 从出手随从拉出一条箭头，**终点停在对方那一排的上空**（不落在任何人身上），终点是一个**乱码准星**：
  - 方形括号准星（边长 0.1），中间的字以每秒 12 次的速度乱跳（数字、字母、方块字随机），颜色噪点灰 `#8A9488`，带静电颗粒。
  - 下面标"待定 ×2"（选几个就写几）。
  - 准星在所有**可选的**目标之间慢慢飘（正弦曲线，来回一趟 2 秒），偶尔抖一下（每 1.5 秒随机一次 40 的横向抖动）。
  - 所有可选目标脚下有一圈很淡的虚线圈（不透明度 0.2），表示"可能是你"。
- 宣告阶段**谁都还没定**（规则：择流的目标要等双方宣告全部结束后才定），所以自己这边也只看到同一个乱码准星，只是颜色是自己的黄绿。
- **定目标阶段**（双方宣告完、结算前，只有择流玩家有这一步）：乱码准星落到己方屏幕的对方一排上空，玩家点谁，谁脚下就扣上一圈黄绿实线括号，旁边小字"仅你可见"；对手屏幕上仍是乱码准星。辅助轮建议的目标先用虚线括号标出来，点"用建议"就变实线。
- 时间轴上这句话的钉子上画一个"?"。
- 声音：准星飘动时有极轻的静电"沙沙"（-26 dB），只在悬停时听得到。

### 5.3 招牌时刻（二）：出手时开镜、扫描、锁定、改锁

**开镜与锁定**

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~120 | "选择"词牌飞到出手随从面前，展开成瞄准镜透镜（直径 0.12）；画面四角压暗角（墨绿黑，不透明度 0.25），场景整体降饱和 20%（主目标候选除外） | 光学变焦"嗞——" |
| 120~420 | **扫描**：透镜里的准星在所有可选目标之间跳（每个停 60），每停一个，那个目标身上闪一下括号，旁边刷出一行小 HUD 读数（"血 4 · 易伤 1"）；乱码的噪点越来越少 | 每跳一下一声"嘀"，静电逐渐变小 |
| 420~520 | **锁定**：准星"啪"地停在真正的目标上，四个括号向中心合拢（`TRANS_BACK`，80），中心出现那颗小红点 `#FF3048`；宣告时的乱码字**逐字解码**成目标名字（80，像老虎机停下） | "嘀、嘀——叮！" |
| 520 | 字幕里"待定"两个字被替换成目标名字（打字机效果） | — |

- **选多个**：透镜分出 N 个准星，扫描时一起跳，锁定时按从左到右的顺序，间隔 60 依次合拢，每个一声"叮"，音高递升。

**改锁**（选中的目标在出手时已经倒下）

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~100 | 准星合拢在原目标的位置，但那里是倒下/休整的随从（灰色）；准星上闪一个红色"×"，小字"目标已倒" | 错误音"嘟" |
| 100~280 | 准星**甩枪**：带一条运动模糊拖尾（黄绿，长 0.15），180 内横扫到下一个合法目标；途中 HUD 文字故障闪烁"改锁" | 快速"唰" |
| 280~360 | 重新合拢锁定，红点亮 | 比第一次高半音的"叮" |
| 同时 | 字幕里原名字加删除线，后面接上新名字："~~刀客~~ → 弓手" | — |

- 没有任何合法目标：准星在原位抖、闪雪花，然后像旧电视关机一样缩成一条横线消失，"无目标 · 落空"，整段按单段落空处理。

### 5.4 造成伤害

**单目标**

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~80 | 这一段的词牌在透镜前压缩成一枚**玻璃弹头**（冷白芯 + 黄绿外壳），数字牌嵌在弹尾 | "咔"上膛 |
| 80~140 | **预瞄线**：从弹头到目标瞬间出现一条极细的黄绿直线（粗 0.002），闪两下 | 极轻"嘀" |
| 140~210 | 弹头沿直线飞（70，`TRANS_QUART` 缓入），身后一道冷白曳光，线条笔直、不抖 | 消音"啾" |
| 210 | **命中**：小而亮——一个刺眼的白点（直径 0.03，亮度 4）+ 一圈 6 根针状火花向外弹；复用 `hit.tscn` 缩到 60%，`color = #C6FF3D`；顿帧 50（干脆）；震屏只有 0.002 | 清脆"叮"+ 很短的玻璃碎响 |
| 210~330 | 数字"−4"弹出，黄绿描边，旁边小字"有效 4"；如果有溢出（目标只剩 2 血）："−4（有效 2）"，溢出的 2 灰色划掉 | 数字烙印"铛"（偏高、偏干） |
| 330~400 | 预瞄线从目标端往回收，消失 | — |

**多目标**：N 个准星各自一条预瞄线，**交替**开火（间隔 60，左右左右），每发都是完整单目标命中；整段像一组短点射。

**重复 N**：同一条预瞄线上**连发** N 发，间隔 90，每发的命中点在目标身上略微错开（0.01 以内，像弹着点分布）；透镜右下角一个小计数"1/3 → 2/3 → 3/3"；最后一发曳光加粗，顿帧 ×1.5。声音："啾啾啾"，最后一发拖一个回声。

### 5.5 恢复

- 0~120：准星换成**十字形**医疗准星（冷白 + 黄绿），锁定友方（锁定动作同上，但没有红点，改成一个薄荷绿十字）。
- 120~260：一枚柔光的"医疗弹"（冷白光球，不是尖的）沿着一条**虚线**慢飞过去（140，`TRANS_SINE`），表示这不是攻击。
- 260~560：碰到友方后绽开成一个十字形的光，往上飘起一串细小光点（300）；复用 `heal.tscn`，`color = #EAF2F0`。
- 数字"+3（有效 1）"——满血溢出的部分灰色划掉。
- 声音："嘀——叮"上行两音 + 柔和的玻璃和声。

### 5.6 减伤

- 0~150：准星锁定友方，十字分划在友方前方投出一块**防弹玻璃面**的线框（HUD 黄绿线条勾边的透明晶面，宽 0.12）。
- 150~350：线框从边缘往中心"填充"成半透明玻璃（像加载条），玻璃上刻 N 道刻度线（N = 减伤值）。
- 整轮：只剩线框（0.25）。挡伤害时玻璃上出现一个白色弹着点 + 蛛网细纹，然后自动修复（200），弹出"减伤 −2"。复用 `shield.tscn` 染黄绿。
- 声音：玻璃成型"叮铃"，挡伤害时"嗒"一声弹着。

### 5.7 施加状态

**易伤 = 弱点标记**：命中后目标身上**留下一颗红点**（激光指示器那种）+ 一圈小括号，等级几级就几层括号（套娃式）。之后整轮这颗红点一直在，每 2 秒脉动一次（不透明度 0.3→0.7）。被别人打中时，红点亮到最大并"嘀"一声——让玩家看到易伤在起作用。

**灼烧 = 燃烧弹**：弹头命中后**从目标内部**点燃：目标身体的轮廓线先亮白，再从轮廓往外冒火——火焰形状是正常的火，但颜色是白热芯 `#FFF6C8` + 黄绿外焰 `#C6FF3D` 的火星；脚下一圈细细的 HUD 燃烧计时（等级 = 格数）。轮末灼烧：计时格跳掉一格，火苗窜一下。

**衰弱 = 干扰**：目标的武器/手上框出一个黄绿 HUD 框，框里写"−1"，框内画面加一层静电雪花；目标宣告的意图箭头（若有）变成虚线。声音：干扰"滋啦"。

### 5.8 转移

挂上：被保护者前方立一块**三棱镜**（冷白玻璃，0.06 高），棱镜边缘一圈黄绿 HUD 线。

触发：
- 0：攻击打进棱镜，棱镜内部亮起，顿帧 40。
- 0~180：攻击变成一束光，在棱镜里**折射**，从另一个面射出，沿一条笔直的线（预瞄线样式）精确回到攻击者。
- 180：命中攻击者（小而亮的命中），"转移 3"。
- 声音："叮"（进镜）+"啾"（射回），干净利落。

### 5.9 延后

- 0~150：准星锁定敌方的句牌，句牌上覆盖一个 HUD 秒表（数字屏，显示"第 4 秒"）。
- 150~(150+N×80)：秒表上的数字**滚动跳**（像老虎机）到"第 6 秒"，每跳一秒一声电子"哔"；时间轴上的钉子同步**瞬移**到新位置（带一帧数字故障）。
- **推出第 10 秒**：秒表跳到"10"后变成"--"，句牌被一圈黄绿扫描线从上到下扫过，扫过的部分像信号丢失一样化成雪花消失，然后按"整句落空"处理。

### 5.10 移除

**精确拆除**：准星依次锁定目标身上的每层保护（每个保护在目标身上显示成一个小 HUD 图标），**每层一发**，间隔 100：命中图标，图标像玻璃一样碎成几片小三角落下。声音：每发"啾—叮"。没有保护：准星扫一圈，HUD 显示"无防护"，这段灰掉。

### 5.11 击倒

| 时间 | 画面 | 声音 |
|---|---|---|
| 0 | 致命一发命中 | "啾" |
| 0~300 | **子弹时间**：全场 0.25 倍速，透镜向目标推近 10%（这是择流唯一允许的推近） | 所有声音变慢、变闷 |
| 300~450 | 锁定括号**炸开**：四个括号和一圈 HUD 碎片向外飞散 | "锁定解除"电子音"嘀嘟" |
| 300~800 | 目标轮廓先描一圈黄绿线，然后从头到脚被一道扫描线**逐行溶解**（像信号被切断），溶解出的细线向上飘散；`kill.tscn` 染黄绿叠底 | 枪声余音 + 一声高频耳鸣"嗡——"逐渐淡出 |
| 450 | 回到正常速度，大字"击倒！" | `down` |

### 5.12 收束与落空

- **收束**：透镜收起，缩成"选择"词牌；其余词牌在命中后已经化为曳光，不回来——只在句牌上**重新亮起**（从暗到亮 200，像弹匣重新装满）。声音"咔嚓"上膛。
- **整句落空**：透镜裂开一道缝，准星闪烁雪花后熄灭；词牌变灰掉落。
- **单段落空**（只有在改锁也找不到目标时才会发生）：见 5.3。

## 6. 血流 · 血墨

> 一句话："句子是一纸血书，'自身'是印章。" 行动点不够时，随从用自己的血来付——血一滴滴流进词牌，词牌被血墨灌满、变重、变红，然后像毛笔一样重重地甩出去，泼在敌人身上。

### 6.1 视觉身份

| 项目 | 设定 |
|---|---|
| 主色 | 血红 `#C8102E` |
| 深色 | 凝血 `#5A0012`，墨黑红 `#1A0306` |
| 底色 | 骨白 `#F2E6D8`（词牌的纸/骨片底） |
| 高光 | 鲜血 `#FF3B4E`（湿润的反光、溅点高光） |
| 点睛 | 亮黄 `#FFD21F`（只用在"血换来的行动点筹码"描边和数字上） |
| 词牌材质 | 骨白纸片/骨片，字是毛笔写的；**付血后**从下往上灌满红墨（材质参数 `fill 0→1`），表面高光变强（湿），下沿挂着将滴未滴的血珠 |
| "自身"的形态 | **印章**：一方小印，印面朝下，付血时印泥变成血 |
| "并"的形态 | 一根血线打的结，把两段串起来 |
| 动作语言 | **沉**：出手前有明显的蓄势（往后拉 120）；飞行是带重力的抛物线，弧低、末段加速（`TRANS_QUAD` 缓入）；命中有挤压（目标压扁再弹回）；收尾慢 |
| 声音质感 | 心跳（"扑通"两拍）、液体灌注、毛笔划纸"唰"、太鼓/大鼓低音、湿拍"啪嗒" |
| 得分反馈 | 付的血（每点）和血付句子打出的伤害，都化成血红小数字飞向职业进度条，标"血付" |

**没有付血时**（行动点够用），血流也保持同一套风格，但是"墨"版：词牌是骨白底黑红字，毛笔动作、沉重手感都在，只是红色少、没有血珠、没有心跳加速。玩家一眼就能分出"这句付了血"和"这句没付"。

### 6.2 招牌时刻：以血付账

只在行动点不够、用生命补差额时播放（P = 付的血量）。插在 A 阶段（起句）之后、出膛之前。

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~150 | 出手随从身体**往里一缩**（像捂住胸口），铭牌上的血条边缘闪红；头顶出现小字"以血代价 3" | 心跳"扑通"一次，很响 |
| 150~(150+P×120) | **每付 1 点血**（120 一次）：一颗光滑的血珠（直径 0.02，`#C8102E`，高光 `#FF3B4E`）从随从胸口挂点（`Socket_chest`）升起，沿一根细血线（0.002）飞到上方悬着的下一张词牌，"啪嗒"滴进去，词牌里的红墨**涨一截**（1/P）；同时：铭牌血条掉 1、随从头上飘红色"−1"；桌上行动点筹码堆旁边生成一枚**血筹码**（血红底、亮黄边）落到堆上 | 每滴一声"啪嗒" + 心跳，**每滴心跳更快、音调更高一点** |
| 同时 | 随从每付 1 点身子往下沉 2%（最多 8%），自发光变暗；画面边缘渗出一圈很淡的暗红暗角（不透明度随 P 增加，最高 0.3） | — |
| 结束 +100 | 所有词牌已灌满红墨，变"重"：整体下沉 0.03，摆动变慢，下沿持续滴血珠（每张每 400 一滴，落到桌上留小血点贴花，本轮内淡出） | 心跳归于一个持续的低沉"咚……咚……" |

- 付到只剩 1 血（规则下限）：随从单膝跪下的姿势，心跳声音最大，血条闪烁。
- 付的血同时**分出一缕**细血流飞向职业进度条（"血付 +3"），表示这也是得分。
- **血契护体**（规则：付了 P 点血，这个随从本轮就多 P 点减伤）：血珠滴完以后，随从胸口的伤口处结出一层暗红血痂甲（半透明晶面，`#7A0F1E`，边缘高光 `#FF3B4E`，厚度随 P 增加，P≥3 时盖住半个身子），150 内从胸口向外"咔"地长满，铭牌旁出现"血痂 −P"标记；本轮这个随从每次被打，血痂先亮一下、裂一道纹，再显示减掉的数；轮末血痂碎成血粉落下（300）。
- 拼句台上的提示（不是战斗特效，但要统一）：当这句话需要付血时，句子里如果放了"恢复"，"恢复"词牌上盖一个血红"封"字印，并且提示"以血付账的句子不能带恢复"。

### 6.3 起句与出膛

- 0~150：句牌升起，像一张展开的纸条（卷轴展开 150）。
- 150~350（付血时在付血之后）：词牌从纸上**一笔一笔**被"写"出来飞起：每张词牌出现时有一道毛笔划过的墨痕，间隔 40；"并"是血线结，把词牌串成一串；"自身"印章悬在最前面。
- 印章落下：如果句子里有"自身"，印章在出手随从身上**盖一下**（红印，150），表示"代价由我出"。

### 6.4 造成伤害

**单目标**

| 时间 | 画面 | 声音 |
|---|---|---|
| 0~120 | **蓄势**：这一段的词牌往出手随从身后拉 0.08，聚成一笔"撇"形的血墨笔锋（长 0.15，前粗后细，后尾拖墨丝） | 毛笔蘸墨"嗞"+ 吸气 |
| 120~320 | **甩出**：笔锋沿抛物线飞向目标（弧高 0.12，前慢后快 `TRANS_QUAD` 缓入），沿途甩下几滴血墨落到桌上 | "唰——" |
| 320 | **命中**：目标被**压扁**（纵向缩到 0.85，60 后弹回 1.05 再到 1）；血墨在目标身上和桌面上**泼开**成放射状墨迹贴花（直径 0.25，边缘有飞溅点）；复用 `hit.tscn`，`color = #C8102E`；顿帧 70；震屏 0.008 + 0.0015×伤害 | 大鼓"咚！" + 湿拍"啪" |
| 320~450 | 数字"−5"：骨白字、血红粗描边，字的下沿**往下滴**（两三颗血珠从字上掉下） | 数字烙印"铛"（偏低、偏闷） |
| 之后 | 墨迹贴花本轮内保留，不透明度 0.4 慢慢淡到 0.15 | — |

**付血加成**：这句话付了血时，命中特效整体放大（1 + 0.1×P），多一圈心跳形状的冲击波（一圈血红环向外扩两次，像"扑通"两拍）。

**多目标**：笔锋变成一笔长长的**"横"**，从左到右横扫过 N 个目标（220），每扫过一个目标就在那一刻命中（压扁、泼墨、数字），横笔末端收锋时一顿（"顿笔"，顿帧 50）。

**重复 N**：笔锋来回**撇、捺**交替砍 N 下（间隔 150），每下在目标身上留一道交叉的墨痕；最后一下是一个重重的"点"——笔锋竖着从上往下戳下去，墨迹炸开最大，顿帧 ×1.5。声音："唰、唰、唰——咚！"

### 6.5 恢复

（血流的恢复只出现在**没有付血**的句子里。）

- 0~150：词牌化成一支饱蘸**清水**的笔（墨色变浅成淡玫瑰色 `#FFB3A6`）。
- 150~550：笔在友方身上**洗一遍**（从头到脚一笔"竖"，400）：友方身上之前留下的血墨痕迹被冲淡，伤口处的暗红化成温暖的淡粉光往上升。
- 550：数字"+3"，薄荷字带淡玫瑰描边；复用 `heal.tscn`，`color = #FFB3A6`。
- **自己治自己**（"自身 恢复"）：桌上的小血点贴花往随从身上**倒流**回去（300），心跳从快变慢。
- 声音：水笔划纸"沙——"，柔和的心跳两下，一声温暖的低音弦。

### 6.6 减伤

**血痂符**：
- 0~200：笔在目标朝敌一侧的空中**写一道符**（朱砂红的笔画，按笔顺写出 3~5 笔，200）。
- 200~350：符**凝固**成一层暗红的血痂盾（凝血色 `#5A0012`，表面有龟裂纹，层数 = 减伤值，一层叠一层往外变厚）。
- 整轮：血痂淡显（0.3）。挡伤害时：最外层掉下一块痂片（落到桌上碎开），弹"减伤 −2"；层数不减（减伤是每次少受，不是一次性），掉下的只是表现。
- 声音：写符"唰唰唰"，凝固"咯吱"（像干涸的泥），挡伤害"喀"。

### 6.7 施加状态

**易伤 = 血契印**：印章（或笔锋）在目标身上**盖一个血印**（方印，红底白字"契"），等级几级盖几个（叠在一起，略错开）；印的四边慢慢渗出细细的红线（裂纹），之后淡到 0.3。声音：盖印"嘭"+ 纸上渗墨的细微声。

**灼烧 = 朱砂火**：目标脚下燃起**血红色火焰**，火焰边缘是黑烟 `#1A0306`，火心是鲜血色；轮末灼烧时火焰猛蹿一下，冒出一团血雾。声音：火"呼"+ 液体沸腾"咕嘟"。

**衰弱 = 抽血**：目标身上垂下 N 根细红线连到桌面（像被抽走力气），目标身形塌 3%，颜色降饱和 20%；红线一直轻轻往下流动。声音：缓慢的"汩汩"声 + 一声叹息般的低音。

### 6.8 转移

**血债**：
- 挂上：被保护者和桌面之间系上一根血线，线上打一个结（"并"的那种结），结悬在被保护者身前，缓慢滴血。
- 触发：攻击打到被保护者，血结**猛地收紧**（顿帧 40），伤害化成一股血流，沿一条新拉出的血线**冲回**攻击者（抛物线，200），在攻击者身上泼开（压扁、泼墨），"转移 3"。
- 声音：心跳**倒放**（"通扑"），然后"啪"。

### 6.9 延后

**镇纸**：
- 0~200：一块墨黑的长条**镇纸**（压书用的那种，刻有血红花纹）出现在敌方句牌上方 0.2。
- 200~300：镇纸**砸下**压住句牌（`TRANS_QUAD` 缓入，砸中时震屏 0.006），句牌被压得一沉。
- 300~(300+N×120)：镇纸每秒往后推一下，句牌在桌面上被拖着往后挪（每下 0.02），留下一道墨痕；时间轴钉子同步走。
- 声音：砸下"咚"，每推一下石头摩擦木头"咯——"。
- **推出第 10 秒**：最后一推把句牌推出桌沿，句牌掉下去，纸张在空中被墨浸透化成一团黑红墨雾，按"整句落空"收尾。

### 6.10 移除

**洗墨**：一大笔血墨从上到下**泼洗**过目标（一道宽笔触，250），目标身上的每层保护像墨迹遇水一样**化开、糊掉、往下流**，流到桌面变成一滩淡红水渍消失。声音：泼水"哗"+ 纸被浸湿的"嘶"。

### 6.11 击倒

**血印 · 倒**：

| 时间 | 画面 | 声音 |
|---|---|---|

### 6.12 收束与落空

- **收束**：词牌在命中时已经泼成墨，不回来；句牌（纸条）卷起来，卷的时候纸面上的字重新**浮现**（从淡到实 300）。付了血的句子，卷起的纸条边缘留一道红色。
- **整句落空**：词牌里的血墨**干涸**：颜色从鲜红变成褐黑、表面龟裂、碎成片片掉落。**如果这句话已经付过血**：碎片掉落时有几滴血珠滴在桌上，字幕后面接小字"血白流了"（付的血是否返还以规则为准，特效只表达"付了"）。
- **单段落空**：笔锋泼到空处，墨迹溅在桌面上，空地盖一个灰色"落空"小章。

## 8. 实现附录（给程序）

### 8.1 现状

- 数字牌模式的结算回放目前是 2D：`godot/scripts/numcard/ui/nc_battle.gd` 的 `_resolve()` 逐个事件写日志、刷新随从卡片（闪红/闪绿），每个事件等 0.35 秒。3D 牌桌（`scripts/view3d/table3d.gd`、`minion3d.gd`）和战斗特效（`scripts/fx/fx_player.gd` + `data/fx.json`）属于老模式，数字牌模式还没接。
- 引擎结算事件（`nc_engine.gd` 产出）：`fire`、`hit`、`redirected`、`reflected`、`heal`、`mit`、`status`、`listen`、`delay`、`remove`、`fizzle`、`ko`、`endure`、`burn`。
- 拼句台已有"飞词组句"代码动画：`scripts/compose/stamp_fx.gd` 的 `combine()`（飞起 → 咔咔拼合 → 变成人话牌），可以借它的手感参数做出膛阶段。
- 设计决议第 7 条："临近上线，先不再改代码"。所以本附录只是**接入方案**，等放开再做。

### 8.2 一套通用的"词飞行"系统

建议做成**一个**播放器（暂名 `WordFlight`，放 `scripts/fx/word_flight.gd`），按"句子 + 事件 + 职业样式"驱动，所有职业差异都在样式数据里，不写四套代码。

**输入**

1. 句子：词牌列表（每张：文字、是否数字牌、数字值、数字来源、属于第几段）。
2. 这句话这一秒产生的引擎事件（从 `fire` 到下一个 `fire` 之前的那一串）。
3. 出手方职业样式（`style_id`：`neutral` / `bing` / `xu` / `ze` / `xue`，第五个职业将来加一行即可）。
4. 敌我（`who = mine / foe`）、出手随从编号、各目标随从的世界坐标/屏幕坐标。

**阶段机**（对应 1.2）：`rise → launch → assemble → clause[i] → return`，外加三个独立入口：`refire`（续流回响）、`break`（续断）、`fizzle`（整句落空）。

**每段播放 = 效果类型 × 职业样式**：段播放器按事件类型选"通用形状"（1.3），再用样式数据里这个职业对这个效果的配置（场景、颜色、时长、缓动、声音）去填。

**需要引擎补的信息**（建议，规则不变，只多带几个字段）：

| 字段 | 放在哪个事件 | 用途 |
|---|---|---|
| `clause` 段号 | `hit`、`heal`、`mit`、`status`、`listen`、`delay`、`remove` | 把事件归到"第几段"，才能按段依次演、做并流关节 |
| `rep` 第几下 / `reps` 共几下 | `hit`、`heal` | 重复计数器、最后一下加重 |
| `refire` 是否回响 | `hit`、`heal`、`mit` | 续流回响版动画 |
| `blood` 付了几血 | `fire` | 血流付血演出 |
| `picked` / `retarget_from` | `fire` 或 `hit` | 择流锁定、改锁动画 |
| `src_class` | `status`、`burn` | 灼烧轮末按施加者职业着色 |
| `link_break` | 新事件 `xu_break` | 续断演出 |
| `overkill` / `overheal` | `hit`、`heal` | 择流"有效"值显示 |

### 8.3 现有特效场景怎么复用

`assets/fx/effect3d.gd` 的 `play(ctx)` 已支持 `ctx.color` 覆盖颜色、`ctx.tier`（0~3）放大，所以现有场景**全部可以按职业染色复用**，只是外形相同，靠在上面叠职业专属的小场景区分。

| `cast.tscn` | 默认样式起句；续流表盘点亮 | 主色 |

| `big_hit.tscn` | 伤害 ≥10（`fx.json` 的 `min_amount`） | 主色 |
| `heal.tscn` | 恢复底层 | 并流 `#7DFFD8`、续流 `#FFD98A`、择流 `#EAF2F0`、血流 `#FFB3A6` |

### 8.6 性能与平台

- 网页版用兼容渲染器：粒子用 `CPUParticles3D`，不用复杂着色器；词牌的"灌墨""电路纹""扫描线"都用一张贴图 + 一个 0~1 参数做，不做实时噪声。
- 同屏上限：词牌 ≤ 60 张、粒子 ≤ 1500、长驻标记（续环、减伤板、状态）≤ 每个随从 3 个。
- 贴花（墨迹、冲击波）本轮结束统一清掉。
- 所有新场景遵守"`lifetime` 到点删除"；长驻的（续环、减伤板）由 `WordFlight` 自己管，轮末或断裂时删除——避开 `FX用途.md` 里"小舞台不清理"那种问题。

### 8.7 2D 退化版（先做 2D 结算时用）

如果数字牌模式先不上 3D 牌桌，同一套样式数据可以驱动 2D 版：

- 世界坐标换成随从卡片的屏幕中心；"高度"换成缩放（离镜头近 = 大）。
- 词牌用 `stamp_fx.gd` 已有的 2D 牌面，飞行、组装、收束全部照搬时间表。
- 3D 场景换成同名的 `Control` 版本（如 `fx/2d/bing_joint.tscn`），没有的就用代码画（光环、线、粒子），颜色和时长用同一张表。
- 镜头推近换成整个战斗层轻微缩放（≤ 4%）。

### 8.8 分步交付建议

1. **最小可玩**：通用阶段机 + 默认样式 + 1.4 字幕 + 1.5 数字烙印 + 1.7 加速/跳过（先让任何一句话都能"词飞出去、按段演"）。
2. **四个职业的招牌时刻**：并流组装与收束、续流挂环/回响/断裂、择流待定/锁定/改锁、血流付血——这四个最能让职业"被认出来"。
3. **四个职业 × 七种效果**：先做伤害、恢复、减伤（最常见），再做状态，最后转移、延后、移除。
4. **击倒终结演出 + 高光时刻**。
5. **声音**：先用通用音 + 变调凑，职业音效最后替换。

### 8.9 检查方法

沿用 `素材与特效接口.md` 第 9 节的截图命令；建议加一个 `--demo=wordfx` 演示入口：依次播放第 7 节的五个例子（四个职业 + 同秒），每个例子跑 1 倍速、2 倍速、跳过三遍，输出逐帧截图，用来核对：顺序是否正确、数字是否始终可读、一句话是否超时、长驻标记是否在轮末清掉。

### 8.10 规则对照（已和规则定稿对齐）

1. 续流"持续 N"：当轮那一次算第 1 轮，以后再来 N−1 次。续环一挂上就亮 N−1 个凹槽，每回响一次熄一个。
2. 续挂着时目标倒下休整：回响照常发生、打空（"空响"），也照样消耗一轮。出手的随从倒下或被【移除】，续直接断（断裂演出）。
3. 择流的目标：宣告时谁都不定；双方宣告全部结束后，择流玩家在"定目标"阶段点（电脑用模拟挑）；出手那一刻揭晓，定好的人已经倒了就自动换人（改锁演出）。
4. 血流付的血在结算一开始（第 0 秒）就扣，句子落空也不返还；付了几点血，这个随从本轮就多几点减伤（血契护体，见 6.2）。
5. 转移整轮有效：本轮每一下打向它的敌方伤害都转回出手的人（不是挡一下就碎）。
6. 职业主色：只上词牌和特效，桌面与界面不变；先用青 / 琥珀 / 黄绿 / 血红四色。美术方向如果最后不接受，用 6 节写的备选（四个职业都用红黄系，靠材质和动作区分）。
